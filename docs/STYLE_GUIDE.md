# 术语、符号与表达规范（全文唯一依据）

**建立**：2026-08-11 16:45
**作用**：全文写作期间符号与术语的唯一出口（章节结构以 `THESIS_OUTLINE.md` 2026-08-11 17:20 重构版的六章结构为准）。任何章节出现与本表冲突的写法，以本表为准并回改章节。
**动机**：多章长文最常见的形式性缺陷不是措辞不美，而是**符号漂移**（同一对象在不同章用不同记号）与**术语混用**（如 patch / 局部块 / 邻域混指同一概念）。这类缺陷在盲审中被视为写作不严谨。

## 1. 数学符号表（全文统一）

### 1.1 点集与几何对象

| 符号 | 含义 | 约束 |
|---|---|---|
| $\mathcal{P} = \{p_i\}_{i=1}^{N}$ | 输入稀疏点云 | $p_i \in \mathbb{R}^3$，$N = 256$（本文 patch 规模） |
| $\mathcal{Q} = \{q_j\}_{j=1}^{rN}$ | 网络输出稠密点云 | $r$ 为上采样倍率，本文 $r = 4$ |
| $\mathcal{Y} = \{y_k\}_{k=1}^{rN}$ | 真值稠密点云（ground truth） | 与 $\mathcal{Q}$ 等势 |
| $\mathcal{S}$ | 目标连续曲面 | $\mathcal{P}, \mathcal{Y} \subset \mathcal{S}$（无噪假设下） |
| $r$ | 上采样倍率 | 整数；本文固定 $r=4$，任意倍率不在研究范围 |
| $N$ | patch 内点数 | 输入 256，输出 1024 |
| $\mathcal{N}_k(p)$ | $p$ 的 $k$ 近邻点集 | $k$ 在首次出现处显式给出 |
| $d(p, \mathcal{S})$ | 点到曲面的欧氏距离 | $\inf_{s \in \mathcal{S}} \|p - s\|_2$ |

**禁止**：用 $X$ / $Y$ 同时表示点云和坐标矩阵；用 $n$ 表示点数（与索引 $i$ 混淆）。

### 1.2 网络与参数

| 符号 | 含义 |
|---|---|
| $G_\theta$ | 生成器（PU-Transformer 主干），参数 $\theta$ |
| $D_\phi$ | 判别器（PU-GAN 判别器），参数 $\phi$ |
| $\mathbf{F} \in \mathbb{R}^{N \times C}$ | 点特征矩阵，$C$ 为通道数 |
| $\mathbf{F}^{(l)}$ | 第 $l$ 层特征 |
| $\mathrm{PSA}(\cdot)$ | Positional Fusion Self-Attention（PU-Transformer 注意力块） |
| $\mathrm{SC}(\cdot)$ | Shifted Channel 多头注意力 |
| $\mathcal{T}_{\text{up}}(\cdot)$ | 上采样单元（特征扩张 + 坐标回归） |

### 1.3 损失与权重

| 符号 | 含义 | 备注 |
|---|---|---|
| $\mathcal{L}_{\text{cd}}$ | Chamfer 距离损失 | 训练期口径，**非论文主表口径** |
| $\mathcal{L}_{\text{unif}}$ | 均匀性损失（PU-GAN uniform loss） | 权重 $w_{\text{unif}} = 0.00191$（实测标定，见 §5.1） |
| $\mathcal{L}_{\text{adv}}$ | 生成器对抗损失 | |
| $\mathcal{L}_{D}$ | 判别器损失 | |
| $w_{\text{adv}}$ | 对抗损失权重 | 基线中为固定常数；**GAAW（训练机制级主创新）的作用对象**是将其改为梯度自适应 |
| $\lambda_{\text{gp}}$ | 梯度惩罚系数 | |
| $g_{\text{cd}}, g_{\text{adv}}$ | 对应损失回传到 $\theta$ 的梯度范数 | $g_\bullet = \|\nabla_\theta \mathcal{L}_\bullet\|_2$ |
| $\rho$ | 梯度尺度比 | $\rho = g_{\text{adv}} / g_{\text{cd}}$；实测初值 $1/82.65$ |
| $s_{\text{cd}}$ | CD 反传占比 | `cd_bwd_share`，B-001 实测均值 0.5446 |

### 1.4 指标（论文主表口径）

| 符号 | 含义 | 唯一计算出口 |
|---|---|---|
| $\mathrm{CD}$ | Chamfer Distance | `eval_cd_hd_official()` |
| $\mathrm{HD}$ | Hausdorff Distance | 同上 |
| $\mathrm{NUC}$ | 均匀性系数（Normalized Uniformity Coefficient） | 同上 |
| $\mathrm{P2F}$ | Point-to-Face 距离 | 需 mesh，仅 PU-GAN 测试集 |
| $\mathrm{cv}_{\text{nn}}$ | 最近邻距离变异系数 | 本文引入的辅助均匀性度量；实测比 NUC 灵敏（0.5265 vs 1.3300） |

**口径纪律**：主表数字**只能**来自 `eval_cd_hd_official()`。训练期 `monitor_cd/hd/nuc` 出现在训练动态图时，必须在图题与正文显式标注「训练期监控口径，与主表不可比」。

### 1.5 统计量

| 符号 | 含义 |
|---|---|
| $\bar{x}_{\text{plateau}} \pm \sigma$ | 平台区均值与标准差（主表报告形式） |
| $\mathrm{SE}$ | 标准误 |
| $2\mathrm{SE}$ | 显著性门槛（CD 0.66% / HD 2.18% / NUC 0.93%，见 §5.1 功效分析） |

## 2. 术语中英对照与用法约束

| 中文 | 英文 | 用法约束 |

| 点云上采样 | point cloud upsampling | 全文统一，不用「点云超分」「点云加密」 |
| 上采样倍率 | upsampling ratio / factor | 统一用「倍率」，不用「比例」「倍数」 |
| 局部块 | patch | **统一用「patch」**（学位论文允许保留通用英文术语），不用「面片」（易与 mesh face 混淆）、不用「补丁」 |
| 保真度 | fidelity | 指 CD/HD 度量的几何逼近程度 |
| 均匀性 | uniformity | 指点分布的空间均匀程度，由 NUC / $\mathrm{cv}_{\text{nn}}$ 度量 |
| 生成器 / 判别器 | generator / discriminator | 不用「生成网络」「鉴别器」 |
| 对抗训练 | adversarial training | |
| 梯度尺度失衡 | gradient scale imbalance | **本文核心问题表述**，全文统一 |
| 梯度自适应对抗权重 | gradient-adaptive adversarial weighting | 本文**训练机制级主创新**的正式名称，首次出现给英文并缩写为 GAAW。不再使用内部代号「M1」。定位红线：主创新在于「问题测量 + 机制适配 + 边界界定」，**梯度范数比公式本身有 VQGAN 自适应判别权重的直接先例，全文禁止写「首次提出该公式」**；亦不得表述为结构级改进（本文未改动 PU-Transformer 骨干结构） |
| 梯度自适应点云上采样网络 | gradient-adaptive point cloud upsampling Transformer | 方法整体的正式名称，缩写 **GA-PUT** = PU-Transformer 生成器 + PU-GAN 式判别器 + GAAW 训练机制。代码类名 `PUTransGAN`、包名 `puvnet` 不随之改名 |
| 平台区 | plateau region | 指训练后期指标趋稳的 epoch 区间 |
| 消融实验 | ablation study | |
| 多目标权衡 | multi-objective trade-off | 不用「多目标平衡」（平衡暗示可同时最优） |
| 帕累托前沿 | Pareto front | |
| 感受野 | receptive field | |
| 位置编码 | positional encoding | |
| 自注意力 | self-attention | |
| 特征扩张 | feature expansion | 指上采样单元中通道→点数的变换 |
| 折叠 | folding | FoldingNet 类二维网格形变机制 |
| 隐式表示 | implicit representation | |
| 有向距离场 | signed distance field (SDF) | |

**首次出现规则**：每个专业术语在**全文首次出现处**给出「中文（English, ABBR）」，此后统一用中文或缩写，不再重复给英文。

**裁定标签保留英文（2026-08-15 定案）**：`ACCEPT`、`REJECT_NULL`、`REVERSE_SIGNIFICANT` 三个标签**不译为中文**，全文以反引号代码格式书写。

| 标签 | 含义 | 判定条件 |
|---|---|---|
| `ACCEPT` | 相对对照组的改善达到预设门槛，接受 | $\Delta \leq -2\,\mathrm{SE}$ |
| `REJECT_NULL` | 偏移量小于门槛，在当前样本量下无法与零区分；**一律不据此宣称有效** | $\lvert\Delta\rvert < 2\,\mathrm{SE}$ |
| `REVERSE_SIGNIFICANT` | 变化方向与预期相反且达门槛，即反向显著 | $\Delta \geq +2\,\mathrm{SE}$ |

保留英文的两条理由：① 它们是**预注册判据的枚举值**，取值由脚本判出并写入 `docs/_thesis_results.json` 的 `verdict` 字段，正文每处裁定须与该字段**逐字一致**（由 `scripts/audit_thesis_numbers.py` 的裁定通道自动核验）；改用中文后「接受／接收／成立」等近义写法极易跨章漂移，而枚举值的唯一性正是可核查性的基础。② 中文行文中的英文标签具有视觉标识作用，使读者可一眼区分「判据机器判出的结论」与「作者的叙述性评价」。

完整阐释写在**第 4.3.2 节**（判据定义处），全文首次出现处（第 2.5.4 节）给简短阐释并指向该节。

## 2.9 断言纪律（硬红线，2026-08-12 新增）

**规则**：全文任何一句陈述，只能属于以下三类之一，且类型必须在句面上可辨。

| 类别 | 允许写法 | 必须满足 |
|---|---|---|
| A. 文献结论 | 「XXX 指出…{{cite:KEY}}」「已有工作表明…{{cite:KEY}}」 | **必挂 `{{cite:KEY}}`**，且该文献确实说过这句话（不是引一篇沾边的顶刊来给自己的推断背书） |
| B. 本文实测 | 「本文实测…」「在本文基线复现中测得…（run 名、口径、存档文件）」 | 必须能回溯到 `runs/` 或 `docs/*.json` 存档，并标口径 |
| C. 本文推断 | 「据此可以推断…」「本文认为…」 | 必须紧邻给出所依据的 A 或 B，且**不得写成既成事实** |

**禁止句式**（写出即视为缺陷，需当场删改）：

- 「大家争论 / 学界争议 / 长期存在争论」——除非能给出**至少两篇立场相反的可引文献**
- 「普遍认为 / 公认 / 共识是」——除非给出综述类引用
- 「已有文献尚未提供 / 前人未讨论 / 目前无人研究」——**"不存在"是最难证的断言**；只能写「据本文检索范围（数据库、检索式、截止日期）内未见」，并在附录列检索式
- 把代码注释、内部实验记录、agent 自己的分析当作外部依据

**溯源要求**：凡涉及"前人是否讨论过某问题"，先查文献，查不到就**降级为 B 类（只报本文实测）**，不得升级为 A 类。宁可少一个卖点，不可多一句假证。

### 2.9.1 研究缺口的合规表述模板（推荐句式，2026-08-12 定）

表述研究缺口时，**不写"前人没意识到 / 前人错了"，改写"前人的关注点落在 X，本文补测 Y"**。前者是替别人作证（不可查），后者是陈述已发表工作的事实焦点（可查）+ 本文实测（可溯）。

**五段式模板**：

1. **既有关注点（A 类，必挂 cite）**——「在<某问题>上，已有工作主要关注 X{{cite:K1}}{{cite:K2}}，其评价与设计围绕<某观测量>展开。」
2. **未被覆盖的观测量（陈述事实，不作价值判断）**——「上述工作报告的指标集中于 <M1, M2>；<本文关心的观测量 Y> 未在其报告范围内。」
   - ✅ 「未在其报告范围内」= 翻开论文就能核对的事实
   - ❌ 「前人未关注 / 未意识到 / 忽视了」= 替作者声明主观状态，不可查证
3. **本文补齐（B 类，带口径与存档）**——「本文在<数据集/倍率/口径>下测量 Y，得到<数值>（run 名，存档文件）。」
4. **贡献界定（C 类，紧邻依据）**——「据此，本文的贡献是提供 Y 的一手实测与<对照组>下的改进证据，而非声明<更强的结论>。」
5. **适用场景（写条件，不写普适）**——「该结果在<明确条件>下可用于<具体用途>；超出该条件的行为未经本文验证。」

**替换对照表**：

| ❌ 越界写法 | ✅ 合规写法 |
|---|---|
| 前人未关注梯度尺度失配 | 已有工作的对抗权重多取为固定超参{{cite:PUGAN}}，其消融围绕权重取值展开；权重与两分支梯度范数比的逐 epoch 关系未在其报告范围内 |
| 学界对是否加对抗训练存在争论 | 〔删除〕；改为只陈述本文对照实验设置 |
| 这是已有文献尚未提供的一手数据 | 据本文检索范围（数据库、检索式、截止日期见附录 X）内未见同口径报告；本文提供该口径下的实测值 |
| 本文方法有效解决了该问题 | 在 PU1K、$r=4$、同机同口径下，本文方法相对<对照组>在<指标>上改善<数值>（<显著性>）；其他数据集与倍率未经验证 |
| 该方法具有广泛应用价值 | 该结果适用于<输入点数/稀疏度/噪声区间>；典型用途为<具体环节>，失效边界见第 5.6、5.8 节 |

**注意**：第 2 段的"未在其报告范围内"仍属可证伪陈述，写之前必须真的翻过所引文献的实验节。若未逐篇核对，只能写第 3~5 段（纯本文实测），不得写第 1~2 段。

**已知历史踩坑**（留痕）：2026-08-12 口头讨论中曾表述"大家争论该不该加对抗训练"，实际依据仅为 `puvnet/models/pu_gan.py:220` 的 docstring（内部代码注释），非文献争论，已收回。经全文 grep 核查，该表述**未进入任何正式章节**；`chapters/ch1_introduction.pre_outline_v2.md:61` 及其 `.bak` 中的「这是已有文献尚未提供的一手数据」属同类越界（旧版草稿，未进当前正文），若复用该文件须先改写为「据本文检索范围内未见」。

## 3. 表达规范（顶刊语体）

### 3.1 必须做到

1. **机制陈述可验证**：写「对抗梯度范数仅为 CD 梯度的 $1/82.65$」，不写「对抗损失作用被削弱」。凡断言必附可测量的量或引用。
2. **因果链显式**：机制 → 现象 → 后果 → 对策，四段完整。不允许「因此性能提升」这类跳步。
3. **限定词精确**：区分「在 PU1K 测试集上」「在 $r=4$ 设定下」「在本文实现中」。禁止无限定的普适断言。
4. **主动语态描述本文工作**，被动语态描述既有方法：「本文构造…」/「该方法被证明…」。
5. **数字带口径**：任何指标数字必须能追溯到「哪个 run / 哪个 epoch / 哪个计算口径」。

### 3.2 禁止出现

| 禁止 | 原因 | 替换为 |
|---|---|---|
| 「显著提升」「大幅改善」（无数字） | 不可验证 | 给出数值 + 是否超过 2SE 门槛 |
| 「众所周知」「显而易见」 | 回避论证 | 给引用或给推导 |
| 「本文方法优于所有对比方法」 | 过度声明 | 「在 CD 指标上优于…，在 NUC 上与…持平」 |
| 「完美解决」「彻底克服」 | 非学术表述 | 「在…设定下缓解了…，代价是…」 |
| 「首次提出」（未做充分检索） | 高风险声明 | 「据我们检索所及，尚未见…」 |
| 感叹号、口语化连接词 | 语体不符 | 删除 |
| 「我们」（中文学位论文） | 体例问题 | 「本文」 |

### 3.3 负面结果的写法

消融组未达门槛时，**不允许**用「略有提升」「趋势向好」等模糊表述掩盖。标准写法：

> 该组相对基线的 CD 改善为 $x\%$，未超过 2SE 门槛（0.66%），按 §3.4 接受准则判定为 `REJECT_NULL`，即在当前样本量下无法确认其有效性。

## 4. 图表规范（大道至简，信息优先）

### 4.1 设计原则

1. **一图一论点**：每张图只回答一个问题，图题即该问题的答案。
2. **无装饰**：不用渐变、阴影、3D 立体效果、多余边框。线宽与字号服从可读性，不服从美观。
3. **信息密度优先**：坐标轴必须标注量纲与口径；多曲线必须直接标注在曲线旁（不用远离的图例）。
4. **黑白可读**：所有图在灰度打印下仍可区分（靠线型与标记，不只靠颜色）。
5. **示意图必须自证身份**：图题含「示意图/框图/流程」，元数据 `depends_on_experiment: false`。

### 4.2 硬性约束（已由自检器强制）

- 中文字体下禁用字符：`⚠ ✓ ✗ ✅ ❌`（渲染为方框）→ 用「注：」「是/否」
- 箭头 `↑ ↓` 实测正常，可用于标注指标方向
- 同层相邻元素间距 ≥ 元素宽度（`selfcheck_schematic.py` 量化校验）
- 训练期口径的图必须在图题标注「非论文主表口径」

### 4.3 必须讲清楚的两条链

本文图表体系必须让读者仅靠图就能理解：

**链 A — 网络前向过程**：输入 patch $\mathcal{P}(256\times3)$ → 特征提取 → PSA/SC 注意力堆叠 → 特征扩张 $\times r$ → 坐标回归 → 输出 $\mathcal{Q}(1024\times3)$。每一步标注张量形状。

**链 B — 训练与评价流程**：数据采样 → 前向 → 多项损失计算 → 梯度尺度测量 → 反传 → 平台区选点 → 官方口径评测 → 显著性判定。每一步标注产物文件名。若 GAAW 经消融验证后进入正文，则在「梯度尺度测量」与「反传」之间补画权重自适应环节；否则该环节仅出现在附录消融图中。

## 5. 引用编排（承 THESIS_OUTLINE §3 纪律 6–8）
