## 1 全文叙事原则：用问题推动证据，而不是用结论倒推材料

### 1.1 论文初衷的柏拉图式问题链

全文开篇不直接宣布“提出 GAAW”，而是依次追问：

1. **为什么需要点云上采样？** 稀疏点云究竟损失了什么几何信息，增密对表面表达和下游处理有什么可验证价值？
2. **为什么已有重建目标仍不充分？** Chamfer 距离较低是否必然意味着输出点分布均匀，还是可能存在多点聚集、局部空洞等度量盲区？
3. **为什么考虑对抗监督？** 判别器能够补充哪一类分布信息，又为什么不能简单地把它视为“必然提升性能”的模块？
4. **为什么固定权重值得怀疑？** 当重建梯度和对抗梯度在训练过程中改变数量级时，一个静态系数还能否持续表达原本期望的相对贡献？
5. **本文真正补充了什么？** 是一个全新的基本公式，还是把已有动态加权思想适配到点云上采样，并测量其收益、代价与失效边界？
6. **数据怎样把问题推到结论？** 原始点云、训练记录、模型权重、逐样本测量、统计汇总、图表和文字主张之间能否形成一条可复查的证据链？

这六个问题构成全文的叙事骨架。第 1 章提出问题，第 2 章寻找已有答案，第 3 章建立分析框架，第 4 章把问题转化为可证伪命题，第 5 章给出方法，第 6 章用数据回答命题，第 7 章只总结已经被证据支持的结论。

### 1.2 一句话技术故事

> 本文在 PU1K 的 4 倍点云上采样设置中，将基于梯度范数比的动态权重适配到 PU-Transformer 生成器与 PU-GAN 式判别器的联合训练，并通过无对抗、固定对抗、自适应对抗和显式均匀性约束的受控比较，探索性观察到动态权重能够缓解特定固定权重造成的局部间距离散，但当前证据不支持其同步改善几何质量或优于无对抗基线。

### 1.3 数据到结论的证据链

```text
PU1K 原始点云
→ 固定划分与 patch 构造
→ 同配置训练与模型选点
→ best.pt 前向推理
→ 每样本 CD / HD / cv_nn / 稀疏分层统计
→ 同一实验批次、同 seed、11 条真实验证交集的探索性配对比较
→ 跨 seed 重复（待补）
→ 主张—证据矩阵
→ 摘要、结论与局限
```

任何不能沿该链回溯的数字，不得进入摘要和第 7 章。
