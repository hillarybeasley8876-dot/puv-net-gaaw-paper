## 1. 命题与研究问题

### 1.1 任务
标准**点云上采样**（point cloud upsampling）：给定稀疏点云 `P ∈ R^{N×3}`，
生成密集点云 `S ∈ R^{rN×3}`，要求贴合原始表面、分布均匀、无离群点。

### 1.2 用户指定的创新点
PU-Transformer 与 PU-GAN 结合。

### 1.3 ⚠️ 关键：不能写成「A+B 拼接」

**如果论文的叙事是「我们把 PU-Transformer 和 PU-GAN 拼起来，效果更好」，
这在硕士论文可以过，但学术价值很低，且主表大概率打不过 RepKPU(CVPR'24)。**

**必须找到一个真实存在的、可量化的矛盾，并给出机制性解法。**

### 1.4 已找到的真实切入点（有文献证据）

来自 PU-Transformer 原论文 Tab.4（噪声鲁棒性，证据见 `docs/PU_TRANSFORMER_SPEC.md` §6.4）：

| 噪声 β | PU-Transformer CD | Dis-PU CD | PU-Transformer HD | Dis-PU HD |
|---|---|---|---|---|
| 0.5% | **0.453** | 0.496 | **4.052** | 6.268 |
| 1% | 0.610 | **0.591** | **5.787** | 7.944 |
| 2% | 1.058 | **0.858** | **9.948** | 10.960 |

**可读出的现象**：噪声越强，PU-Transformer 在 **CD 上的优势反转**（β=2% 时 1.058 输给 0.858），
但 **HD/P2F 始终领先**。

**机制解释（本文的核心论点）**：
- PU-Transformer 只用 modified CD 损失训练（原文明写「we **only** use the modified CD loss」）
- CD 损失是**平均最近邻距离** —— 它对「点堆在一起」不敏感：只要每个点附近有 GT 点，CD 就低
- 因此纯 CD 训练的模型在强噪声下会出现**局部密度失衡**（分布不均），而 CD 指标恰好惩罚不到位
- PU-GAN 的**对抗损失 + uniform 损失**正是直接优化分布均匀性的
- **两者互补而非重复** → 这是「结合」的学术理由，不是拼接

### 1.5 本文的三个研究问题（RQ）

- **RQ1**：纯 CD 训练的 Transformer 是否确实存在局部密度失衡？如何量化？
  → 用 NUC 指标 + 噪声梯度实验验证（不能只靠推理）
- **RQ2**：引入对抗与均匀性约束能否修复该失衡，且不牺牲 Transformer 的 HD/P2F 优势？
  → 三组对照：纯 Transformer / 纯 PU-GAN / 本方法
- **RQ3**：融合过程本身有哪些工程矛盾，如何系统性解决？
  → M1/M2/M3 三项机制的消融（见 §3.3）

**RQ1 是本文相对「A+B」叙事的关键差异** —— 先诊断问题，再给解法，而不是先拼再解释。

## 2. 标题与命名

### 2.1 方法命名（全文统一，不得出现第二个名字）

**`PUTG-Net`**（PU-Transformer-GAN Network）

- 旧稿的 `PUV-Net` / `Volume-Upsampler` / 「体积感知网络」**全部废弃**
- 代码中类名为 `PUTransGAN`，论文中统一称 `PUTG-Net`，并在方法章首次出现时说明对应关系

### 2.2 标题候选

| # | 中文标题 | 侧重 | 评价 |
|---|---|---|---|
| **A**（推荐） | **基于 Transformer 与对抗学习协同的点云上采样方法研究** | 机制协同 | 准确、不夸大、覆盖两个组件 |
| B | 面向分布均匀性的 Transformer 点云上采样方法研究 | 问题导向 | 更贴 RQ1，但弱化了 GAN |
| C | 融合自注意力与对抗约束的点云上采样网络 | 技术组合 | 偏「拼接」叙事，不推荐 |

**推荐 A**。理由：「协同」比「结合/融合」更能体现 §1.4 的互补机制，且不会让审阅人第一眼想到「A+B」。

英文（备投稿用）：
`Synergizing Transformer Representation and Adversarial Regularization for Point Cloud Upsampling`

### 2.3 摘要骨架（数字全部 TBD，等实验回填）

```
【背景】点云上采样旨在从稀疏、不规则的扫描数据生成密集高保真点云。
【现状与缺口】基于 Transformer 的方法（如 PU-Transformer）凭借全局自注意力
    在几何保真度指标（HD/P2F）上表现优异，但其训练通常仅依赖 Chamfer
    Distance 损失。本文指出，CD 损失对局部密度失衡不敏感，导致此类方法
    在输入噪声增强时出现分布均匀性退化 —— 这一现象在 [TBD: 我们的实测]
    中得到定量确认。
【方法】本文提出 PUTG-Net，将 Transformer 的全局特征建模与对抗-均匀性
    约束进行协同优化。针对二者融合中的三个具体矛盾（损失梯度尺度失配、
    判别器主导导致的生成器退化、训练早期对抗信号噪声），分别提出
    梯度范数自适应权重、谱归一化与判别器更新频率控制、对抗损失渐进引入
    三项机制。
【实验】在 PU1K 与 PU-GAN 两个标准基准上，按 4×/16× 上采样及
    β=0.5%/1%/2% 噪声条件进行评测。结果表明 [TBD]。
    消融实验验证了 [TBD]。
【结论】[TBD]
```

⚠️ 摘要里每个 `TBD` 都必须由 EXPERIMENT_LOG 的真实 run 填充。
**若实验不支持某个论断，改论断，不改数据。**
