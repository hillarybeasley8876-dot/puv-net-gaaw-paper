## 2. 结构与编号

### 2.1 章节层级（只到三级）
```
第4章 基于梯度自适应对抗权重的点云上采样方法    ← 黑体16 粗 居中
4.1 方法总览                                    ← 黑体15 左
4.1.1 问题形式化                                ← 黑体14 左
1. 段内小标题                                   ← 宋体12 左 无缩进
```
- **不使用四级编号**（`4.1.1.1`）。需要再分层时用「1. / 2. / 3.」段内小标题（[183] 实证）。
- 章标题「第4章」与标题文字之间**空一个全角空格**（示例 [157]`第1章 引言`）。
- 节标题「4.1」与文字之间**空一个半角空格**（示例 [158]`1.1 概述`）。

### 2.2 图表公式编号
- **章内连续编号**：图 4.1、图 4.2……表 4.1……公式（4.1）。跨章重置。
- **图题在图的下方**，**表题在表的上方**（[188] vs [192] 位置实证）。
- 公式独占一行，编号右对齐，用**全角括号**「（4.1）」（[185] 实证）。
- 正文引用图表用「如图 4.2」「如表 3.1」（[186][191] 实证），**不写「下图」「上表」**。

### 2.3 引用标注
- 正文内用**方括号数字上标**：`……客观规律。”[1]虽然……`（[165] 实证）。
- 参考文献表按 **GB/T 7714**，标注文献类型：`[J]` 期刊 / `[M]` 专著 / `[P]` 专利 / `[D]` 学位论文 / `[C]` 会议论文。
- 中文文献用**全角逗号**分隔作者、全角括号标卷期：`计算力学学报，2001，18（1）：74-80.`（[203] 实证）。
- 英文文献用**半角逗号**、但卷期括号仍为全角：`J.Differential Equations，2020，269（9）：6941-6987.`（[206] 实证）。
  → **注意**：示例中英文条目也用了全角逗号和全角括号，从模板取值。

## 3. 写作施工约定（本项目附加，不与上表冲突）

### 3.1 Markdown 中间稿的映射
本项目章节以 Markdown 撰写（`docs/chapters/*.md`），最终转 Word。映射规则：

| Markdown | 目标 Word 元素 |
|---|---|
| `# 第4章 XXX` | 章标题（黑体16粗居中） |
| `## 4.1 XXX` | 一级节（黑体15左） |
| `### 4.1.1 XXX` | 二级节（黑体14左） |
| `**1. XXX**` 独占一行 | 段内小标题（宋体12左无缩进） |
| 普通段落 | 正文（宋体12，行距固定20pt，首行缩进24pt） |
| `图 4.1 XXX` 独占一行（紧跟图后） | 图题（宋体10.5居中） |
| `表 4.1 XXX` 独占一行（紧接表前） | 表题（宋体10.5居中） |
| `$$...$$ \tag{4.1}` | 公式 + 右对齐全角编号 |
| `{{cite:KEY}}` | 转换期替换为上标 `[N]` |

### 3.2 禁止事项
- **禁止四级编号**（`4.1.1.1`）。
- **禁止「下图/上表/如下所示」**，必须写明编号。
- **禁止图题写在图上方、表题写在表下方**。
- **禁止正文段落省略首行缩进**（除段内小标题、公式、图表题）。
- **禁止半角括号做公式编号**（必须「（4.1）」而非「(4.1)」）。
