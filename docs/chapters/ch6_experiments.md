# 第6章 实验结果与边界分析

## 6.1 实验设置

### 6.1.1 数据集、训练配置和复现条件

本章全部指标在同一验证子集上测得。数据集为 PU1K 的 patch 形式，共 69000 个样本；按 `val_ratio = 0.05` 取尾部区间 $[65550, 69000)$ 为验证区间，在该区间内以固定随机种子 20260811 抽取 $n = 200$ 个样本作为本章唯一的评测集合。上采样率固定 $r = 4$，输入 patch 规模 $N = 256$，输出 $rN = 1024$；推理阶段关闭数据增强，噪声强度置零。

训练配置在全部 9 个论文级 run 之间共享，以满足第 4 章第三项设计约束（不得依赖对超参数的单独调优）：`batch_size = 64`、`epochs = 150`、优化器与学习率调度、梯度裁剪阈值均与第 3.4.5 节的干净基线一致。每个消融组相对其对照组仅改动一个变量，改动项在表 6.1 中逐行列出。

复现条件按机器分列。3090 组运行于 `NVIDIA GeForce RTX 3090`，`torch 2.5.1+cu121`，CUDA 12.1；5090 组运行于 `NVIDIA GeForce RTX 5090`，`torch 2.11.0+cu128`，CUDA 12.8。两组的软件栈版本不同，这是本章不做跨机器绝对值比较的直接原因（详见 6.7.2 节）。

### 6.1.2 对照方法、消融组和实现来源

本章的对照结构分三层，逐层回答不同问题。

**第一层：无对抗基线（B0）。** 即第 3.4.5 节的干净基线，$w_{\mathrm{adv}} = 0$、$w_{\mathrm{unif}} = 0$，纯 Chamfer 距离监督。它回答"不引入任何辅助项时系统处于什么水平"，是 3090 组全部消融与 5090 组预注册裁定的共同参照点。

**第二层：固定权重对抗训练（B1）。** 引入判别器且 $w_{\mathrm{adv}}$ 取常数 8.27。该值来自 B-001 试跑中对抗权重训练期监控量的实测均值（取值依据见第 5 章），而非任意选取——这一点是 B1 作为对照组能够成立的前提，否则"GAAW 优于某个随手选的固定值"不构成有意义的结论。

**第三层：梯度自适应赋权（B2 / GAAW）。** 与 B1 的唯一差异是 $w_{\mathrm{adv}}$ 的给定方式。这是本文的方法组。

三层之间的比较关系是：B0→B1 回答"引入对抗分支的效果"（6.3.1 节），B1→B2 回答"给定对抗分支后，赋权方式的效果"（6.3.2 节，本文主对比），B0→B2 回答"本文方法相对不用对抗训练的总体位置"（6.3.3 节）。三者不可互相替代，尤其 B1→B2 的结论不能推广为 B0→B2 的结论。

实现来源方面，生成器复现自 PU-Transformer[92]，判别器复现自 PU-GAN[64]，均匀性损失沿用 PU-GAN 原文权重，注意力缩放为标准 Transformer 做法[40]。GAAW 的梯度范数比思想与 VQGAN 的自适应判别权重[116]存在直接先例，本文不声称首次提出该公式，其贡献定位为在点云上采样场景中完成问题测量、机制适配与边界界定（见第 5 章）。

### 6.1.3 评价指标、模型选点和统计口径

本章报告三项指标，均为越小越好。

**$\mathrm{cv}_{\mathrm{nn}}$（局部间距离散度）** 刻画输出点云内部最近邻间距的变异系数，直接对应上采样任务所要求的"点分布均匀"这一目标。它是本章的主指标。

**CD（Chamfer 距离）** 刻画输出相对真值的平均几何保真度。它对整体形状偏移敏感，但对局部聚簇不敏感——两个 CD 相同的输出可以在均匀性上相差甚远，这一点在第 3 章的基线诊断中已由实测确认。

**HD（Hausdorff 距离）** 刻画最坏区域的风险，即输出中偏离真值最远的那一部分点的偏离幅度。

三项联合报告的必要性在于它们不可互相替代：仅报 CD 会掩盖均匀性缺陷，仅报 $\mathrm{cv}_{\mathrm{nn}}$ 无法排除"以牺牲保真度换均匀"的退化解。6.5.3 节的权衡分析正建立在这一互补关系上。

**模型选点。** 各 run 的报告指标取自其 `best.pt` 检查点，选点规则由训练期的加权综合分数决定，规则在全部 run 间一致且在训练开始前固定。各 run 的 best epoch 已在表 6.2、表 6.3 中列出；其中 `ABL_AC_combo` 的 best epoch 为 61，显著早于其余各组，该现象在 6.4.2 节单独讨论。

**统计判据。** 本章的接收判据在实验开始前定死，记录于 `docs/_thesis_results.json` 的 `criteria` 字段，全章不作事后调整：

- $\Delta \leq -2\,\mathrm{SE}$：判 **ACCEPT**（相对对照有改善）；
- $|\Delta| < 2\,\mathrm{SE}$：判 **REJECT_NULL**，即在当前样本量下无法与零区分；
- $\Delta \geq +2\,\mathrm{SE}$：判 **REVERSE_SIGNIFICANT**（反向显著，即劣化）。

其中 $\Delta$ 一律以"实验组减对照组"计，$\mathrm{SE}$ 为两组标准误的合并值 $\sqrt{\mathrm{SE}_1^2 + \mathrm{SE}_2^2}$。

此处必须明确该判据的效力边界，否则本章后续所有裁定都会被读者高估。**本章的 $\mathrm{SE}$ 是跨样本标准误，不是跨随机种子标准误。** 它由 200 个验证样本的样本间波动算得，回答的问题是"在这 200 个样本上观察到的组间差异，是否可能仅由样本选择的偶然性造成"。它**不**回答"换一个随机种子重训，该差异是否仍然出现"。后者需要多种子重复实验，本文未做（理由见 6.6.2 节），因此本文全文不报告种子稳健性，也不将任何本章结论表述为"统计显著"。凡本章写"改善"，其完整含义是"在这 200 个验证样本上方向一致，且幅度超过样本波动的 2 倍"。

按此界定，$2\,\mathrm{SE}$ 这一倍数是本文自设的门槛而非领域通行标准，故其作用是**约束本文自身**：它在实验前定死，因此结果出来后无论有利与否都不再改动。6.3.2 节涉及一项未达该门槛的观察，本章按原门槛如实裁定，不作放宽。

### 6.1.4 证据文件与复现路径

为使本章每一个数字可被独立核查，此处列出证据文件的组织方式与复现路径。

**数据入口的单一化。** 本章正文、表格与插图的全部数字来自 `docs/_thesis_results.json` 一个文件。该文件由 `scripts/build_thesis_results.py` 从测量产物汇总生成，其 `purpose` 字段明确规定"论文全文唯一数字入口，正文、表格、图形一律从本文件读数，禁止在正文中另行敲入数字"。设置单一入口的原因是：本项目的测量产物分散于 9 个 run 目录与多份诊断 JSON，若各章分别从原始产物取数，极易出现同一量在不同章节口径不一致而无人察觉的情形。

**两级溯源链。** 每个数字可沿两级回溯：第一级从 `_thesis_results.json` 的 `source_field` 字段指向 `docs/_cv_nn_measure.json` 中的具体键；第二级从该测量文件的 `runs.<name>` 指向 `runs/<name>/` 目录下的原始产物（`history.json` 逐 epoch 记录、`metrics.json` 逐样本记录、`config.yaml` 训练配置、`env.json` 运行环境、`selection.json` 选点记录）。

**关键核验的留痕。** 三项核验已完成并落盘。其一，抽样索引的落域核验：经 `scripts/_adjudicate_n11_claim.py` 逐条检查，9 个论文级 run 各自的 200 条样本索引全部落在验证区间 $[65550, 69000)$ 内，区间外 0 条。其二，与第 3 章诊断口径的一致性核验：本章测量脚本 `scripts/measure_cv_nn.py` 逐字复用第 3 章 `ch3_diagnose.py` 的度量实现，比对的相对偏差为 $0.000×10^{0}$，故本章数字与第 3 章基线诊断可直接对照，不存在口径漂移。其三，数字审计的篡改测试：审计脚本配有负例表，逐个篡改正文关键数字以确认审计器能够检出，避免"审计通过"实为"审计通道失效"。

**插图的元数据。** 三张数据图各配一份 `.meta.json`，记录该图的选样规则、色标口径、离群点处置与已知局限。其作用是使图中不便以文字完整表述的判据（如放大窗口的自动选定准则、色标是否跨样本共享）同样可核查。

## 6.2 数据预分析与基线诊断

本节复述第 3 章诊断结论中与本章裁定直接相关的三项，作为后续假设检验的事实前提。三项的完整推导与证据见第 3 章，此处不重复论证过程。

### 6.2.1 指标方向性和极端对照校准

第 3.4.4 节以极端对照模型标定了各指标的有效取值范围，其中一项结果直接决定本章的报告策略：均匀性完全退化的 `copy4` 构型（将每个输入点原地复制四份）在 NUC 上给出 1725.3 的极端值，而在 P2F 上的失配值为 $2.19×10^{-7}$，与理想构型同量级。

该标定说明**各指标的盲区互不重叠**：P2F 无法检出均匀性退化，CD 无法检出局部聚簇。因此本章必须联合报告多项指标，任一单项指标的改善都不足以支持"输出质量提升"这一整体结论。这是 6.1.3 节三项指标联合报告要求的实证依据，而非写作惯例。

### 6.2.2 无对抗基线的局部间距离散现象

第 3.5.2 节在 200 样本上实测：无对抗基线输出点云的 $\mathrm{cv}_{\mathrm{nn}}$ 均值为 0.2268，真值点云为 0.0538，比值 4.22 倍，且 200 个样本中预测点云的 $\mathrm{cv}_{\mathrm{nn}}$ 全部高于对应真值，无一例外。同时两者的平均最近邻间距接近（预测 0.0404，真值 0.0441，比值 0.916）。

这一对照给出了瓶颈的确切形态：**基线输出的点数与平均密度基本正确，问题在于间距的离散程度为真值的 4.22 倍**，即存在局部聚簇与相应的局部空洞，而非整体过密或过疏。本章以 $\mathrm{cv}_{\mathrm{nn}}$ 为主指标即源于此——它直接度量该缺陷，而 CD 不能。

进一步地，第 3.5.2 节实测 200 样本上 $\mathrm{cv}_{\mathrm{nn}}$ 与 CD 的秩相关仅为 $-0.217$，平台区内 CD 与 NUC 的秩相关为 $-0.571$。两项证据合并说明：**在纯 Chamfer 距离监督下继续压低 CD 不会改善均匀性，甚至与之轻微相悖。** 这是本文引入辅助监督（均匀性损失或对抗损失）的直接动因。

### 6.2.3 稀疏分层、双向 Chamfer 分量和相关性

第 3.5.1 节实测双向 Chamfer 的后向分量在训练全程 150 个 epoch 中无一次低于 0.5，推理期 77.0% 的样本后向占优，训练期后向占比均值为 0.5446。

第 3.5.3 节按"真值点到输入稀疏点云的最近距离"将真值点分为四个分位区间（Q1 最密至 Q4 最疏），实测各区间后向 Chamfer 分量均值依次为 $4.743×10^{-4}$、$5.404×10^{-4}$、$5.469×10^{-4}$、$7.001×10^{-4}$，单调递增，最疏区间为最密区间的 1.476 倍。

这两项事实是 A 系设计的出发点（提高后向权重以强化对真值的覆盖），也是本章 6.4.1 节判定该设计失效的对照基准。同时，$Q_4/Q_1$ 比值被列为本章的分层观测量：若某项改进作用于稀疏区聚合，该比值应下降；若比值不变而整体指标改善，则说明改进作用于其他环节，机制解释须相应修正。

## 6.3 核心假设检验

### 6.3.1 无对抗基线与固定对抗权重 B1

**这一结果对本文的方法定位具有决定性意义，须明确陈述：在本文的实现与超参配置下，引入固定权重的对抗分支损害了主指标。** 该事实不因其对本文不利而省略。它的直接含义是，本文的方法论主张不能表述为"对抗训练改善点云上采样质量"——这一表述在本文实测中不成立。

该现象的一个与实测方向一致的解释是：对抗损失提供的是分布级监督，其梯度并不显式约束局部间距的均匀性；当其权重相对重建损失偏大时，优化过程被推向"整体分布像真值"而非"局部间距均匀"，从而抬高 $\mathrm{cv}_{\mathrm{nn}}$。第 5 章的梯度尺度实测（对抗梯度约为 CD 梯度的 $1/82.65$，而固定权重 8.27 使其有效贡献被放大）为该解释提供了量级层面的支持。但**该因果链未经针对性的受控实验验证，本文将其作为推断提出，不作为定论**。

正是这一结果确立了本章主对比的对照选择：既然引入对抗分支本身有代价，那么"GAAW 是否有价值"这一问题的正确对照就不是 B0，而是同样承担了该代价的 B1。若以 B0 为对照，测得的差值同时包含"引入对抗分支"与"权重如何给定"两项效应，无法归因到本文的机制贡献。

### 6.3.2 固定权重 B1 与自适应权重 B2（本章主对比）

本节是本文对外的核心对比。B1 与 B2 同机器、同批次、同随机种子、同 batch size，唯一差异是对抗损失权重的给定方式。

**主结论。** 在均匀性指标 $\mathrm{cv}_{\mathrm{nn}}$ 上，GAAW 相对固定权重改善 $6.43\%$，偏移量达跨样本标准误的 8.48 倍，判 ACCEPT。该改善是本文的核心实测结果，也是第 4 章 H3 接收条件（$\Delta\mathrm{cv}_{\mathrm{nn}} \leq -2\,\mathrm{SE}$）的满足。

该结论的稳固性来自倍数本身的量级。8.48 倍标准误意味着：即使把判据门槛提高到通行的 $1.96\,\mathrm{SE}$、或进一步提高到 $3\,\mathrm{SE}$、$5\,\mathrm{SE}$，该结论均不改变。换言之它不依赖本文所选的具体门槛值。

**CD 与 HD：方向向好但不作有效性主张。** 两项的点估计方向同为改善，分别为 $-1.36\%$ 与 $-1.69\%$。这一方向本身是有信息量的结论：它表明**均匀性的改善未以几何保真度或最坏区域风险的恶化为代价**，即本文方法不属于"以牺牲保真度换均匀"的退化解。此点对上采样方法尤为关键，因为强行均匀化输出的最常见失效模式正是整体形状偏移。

但两项的偏移量分别仅为跨样本标准误的 **0.32 倍**与 **0.35 倍**，远低于实验前设定的 2 倍门槛，均判 `REJECT_NULL`。故本文**不对 CD 与 HD 作有效性主张**：在当前样本量下，二者的改善无法与零区分，其观察值与"GAAW 对 CD/HD 无影响"这一假设完全相容。

此处按原门槛裁定，理由须写明。$2\,\mathrm{SE}$ 门槛系本文自设，但正因其自设，事后放宽即构成对预注册判据的违反，其效果等同于按结果调整判据。且该门槛的松紧在此处并不影响结论：0.32 与 0.35 的倍数距任何常用门槛（$1\,\mathrm{SE}$、$1.96\,\mathrm{SE}$、$2\,\mathrm{SE}$）均有显著距离，即使采用最宽松的 $1\,\mathrm{SE}$ 亦不通过。这不是门槛过严，而是在 200 样本量下该量级的差异被样本波动完全覆盖。

作为对比，$\mathrm{cv}_{\mathrm{nn}}$ 的 8.48 倍与 CD 的 0.32 倍相差 26 倍。两者不可混为一谈，本文亦不将三项指标合并表述为"全面改善"。

**H2 的裁定。** 第 4 章预注册的 H2 接收条件为 $\Delta\mathrm{CD} \leq -2\,\mathrm{SE}$。实测 $|\Delta|/\mathrm{SE} = 0.32$，**H2 不成立**。按第 4 章"H1–H5 逐条独立"的总判定规则，H2 的失败不否定 H1、H3、H4：H1、H4 验证机制存在（已在第 5 章满足），H3 验证机制带来均匀性改善（本节满足），三者与 H2 无逻辑蕴涵关系。本文因此保留机制论述与均匀性主张，同时明确 CD 维度的改善未获实测支持。

### 6.3.3 自适应权重 B2 与无对抗基线

由表 6.2，B2 相对 B0 的 $\mathrm{cv}_{\mathrm{nn}}$ 上升 $7.47\%$（$7.68$ 倍合并标准误），反向显著；CD 上升 $1.73\%$（$0.43$ 倍），HD 下降 $4.84\%$（$1.02$ 倍），二者判 `REJECT_NULL`。

将本节与 6.3.1 节并读可得一组完整事实：B1 相对 B0 劣化 $14.86\%$，B2 相对 B0 劣化 $7.47\%$，即**在已引入对抗分支的前提下，自适应赋权把该劣化幅度减半**。这正是 6.3.2 节主对比所度量的内容，两处结论一致。

但"减半"须给出正确读法，此处是本文最容易被误读的一处。**它不构成"GAAW 使模型优于无对抗基线"的证据。** B2 相对 B0 的主指标仍高出 $7.47\%$，方向为劣化且反向显著。本文的主张严格限定为：

> 若采用对抗训练，则梯度自适应赋权优于固定权重赋权。

而**不是**：

> 采用 GAAW 的对抗训练优于不采用对抗训练。

后一命题在本文实测中不成立。第 4 章预注册的 H5 即为该项的执行性条件——要求据实报告 B2 相对无对抗基线的各项指标而不省略反向变化。本节的报告履行了该条件。

这一限定同时说明了本文方法的适用前提：GAAW 的价值出现在"已经决定使用对抗训练"这一场景中。若使用者尚未决定是否引入对抗分支，本文的实测结果并不支持引入。

由此产生一个必须直面的问题：**既然 C1 更简单、代价更低且同样通过 ACCEPT，本文方法的价值何在？** 本文的回答分三点，且不回避该竞争关系。

**第一，两者的对照层次不同，不构成同一问题的两个答案。** C1 的对照是无辅助项基线，回答"是否应引入显式均匀性约束"；B2 的对照是固定权重对抗训练，回答"已决定使用对抗训练时如何赋权"。若使用者的技术选型中不含对抗训练，则本文方法不适用，此时 C1 是更好的选择——本文明确承认这一点。

**第二，本文未测量二者的组合。** C1 与 B2 分处不同机器批次，本文未做 "C1 + GAAW" 的组合实验，因此无法判断二者的收益是否可叠加。这是本文的一项明确局限（见 6.7.2 节），也是最直接的后续工作。

**第三，$Q_4/Q_1$ 分层指标显示二者机制不同。** C1 的 $Q_4/Q_1$ 为 1.7038，相对基线的 1.4760 上升；而 B2 为 1.6257，相对 B1 的 1.6296 基本持平。按第 3.5.5 节预设的分层判据，C1 的比值上升说明其作用机制**不是**改善稀疏区聚合，而是在全局尺度压低间距离散度，其代价集中于输入稀疏的区域。这一点是预注册的分层观测量起到实际鉴别作用的一例，也说明两种方法即使在主指标上表现相近，其作用位置并不相同。

综合三点，本文对 C1 的定位是：**它是一个更简单且有效的竞争方案，本文如实报告其优势，并将本文方法的适用范围限定在"已采用对抗训练"这一前提之内。** 本文不通过省略 C1 的结果或淡化其表现来突出自身方法。

## 6.4 消融实验与影响因素

### 6.4.1 双向 Chamfer 权重 A1 和 A2

A 系的设计假设来自 6.2.3 节的实测：基线双向 Chamfer 的后向分量占比偏高（训练期均值 0.5446，150 个 epoch 无一次低于 0.5），且误差随输入稀疏度单调上升（$Q_4/Q_1 = 1.476$）。据此假设，提高后向权重可迫使输出更充分地覆盖真值稀疏区，从而间接改善均匀性。

该假设在实测中被否定，且否定得相当彻底。A1 采用温和加权（$w_{\mathrm{fwd}} = 1.078971$、$w_{\mathrm{bwd}} = 0.921029$），$\mathrm{cv}_{\mathrm{nn}}$ 反而上升 $4.56\%$（$4.92$ 倍标准误，反向显著）；A2 采用激进加权，$\mathrm{cv}_{\mathrm{nn}}$ 推高至 0.563454，为基线的 2.48 倍（$179.90$ 倍标准误），同时 CD 上升 $26.32\%$、HD 上升 $31.55\%$，三项全部反向显著。

**两组结果呈单调关系——加权越激进，劣化越严重。** 这一单调性排除了"A1 的失败源于权重选取不当"这一解释：若存在一个有效的加权区间，则激进加权应当越过最优点后才劣化，而实测显示从温和到激进全程单调恶化，方向自始即错。

此处须注意 A1 的一项细节：其 $Q_4/Q_1$ 为 1.4388，相对基线的 1.4760 略有**下降**。即按 6.2.3 节的分层判据，A1 确实在一定程度上缓解了误差的稀疏区集中——设计意图的这一部分实现了。但主指标同时劣化，说明该缓解是以全局均匀性为代价换取的：把优化压力从密集区转向稀疏区，稀疏区的相对误差下降了，而整体间距分布变得更不均匀。

一项可测量的解释是 A2 的 HD 逐样本离散度显著异常。其推理期逐样本 HD 的变异系数为 1.037，是其余各 run（$0.451$–$0.505$）的约 2 倍；超过中位数 2 倍的样本数为 19，超过 5 倍的样本数为 **4**，而其余 8 个 run 超过 5 倍者**均为 0**（数据来源 `F5_2_hd_epoch_curve.meta.json` 之 `inference_per_sample_hd_spread`）。即激进反向加权在部分样本上产生了严重的局部失效，而非在全体样本上均匀地略微变差。该现象与"反向 CD 主导优化后模型倾向于把点堆向真值密集区、从而在稀疏区留下大空洞"这一机制方向一致；本文将该关联作为推断提出，其直接的逐点证据未在本文实测范围内取得。

**A 系的结论**：双向 Chamfer 的权重调整无法替代显式的均匀性约束。这一结论的价值在于它划定了一条边界——均匀性缺陷不能通过重新分配既有重建损失的内部权重来修正，必须引入独立的均匀性监督项（C1）或分布级监督（B 系）。该结论仅适用于本文所实现的双向 Chamfer 加权形式与所测权重区间。

### 6.4.2 无效补测 D1 的隔离与组合策略 AC

**D1：注意力缩放的隔离实验。** 在 SC-MSA 的 $QK^\top$ 上补 $1/\sqrt{d}$ 缩放（`puvnet/models/pu_transformer.py:289`）后，三项指标同时崩塌：$\mathrm{cv}_{\mathrm{nn}}$ 上升 $100.54\%$（$88.08$ 倍标准误），CD 上升 $415.70\%$（$30.95$ 倍），HD 上升 $1216.99\%$（$27.36$ 倍）。

本文对该结果的定位须精确。它**不**表明"缩放点积注意力是错误设计"——该设计在 Transformer 文献[40]中的作用已被广泛确立。它表明的是：在本文所复现的这一具体实现中，其余超参（学习率、损失权重、初始化）是在无缩放条件下调定的，单独补上缩放会改变注意力 logits 的量级分布，使原超参配置失效。因此 D1 的正确读法是"该修改需伴随超参重调，本文未做该重调"，而非"该修改本身有害"。

本文将 D1 列为**排除性实验**而非改进点。其价值有二：其一，证明本文对基线的复现中该省略是已知的、被检验过的，而非未察觉的实现偏差；其二，确立了"其余各组保持该开关关闭"这一决定的实证依据——若在其他消融组中默认开启该缩放，其影响（主指标翻倍）将完全掩盖被测机制的效果（数个百分点）。

**AC：组合策略的倒赔现象。** A 与 C 的组合（`ABL_AC_combo`）$\mathrm{cv}_{\mathrm{nn}}$ 为 0.243689，相对基线上升 $7.44\%$（$8.47$ 倍标准误，反向显著）；CD 上升 $4.32\%$、HD 上升 $4.75\%$，二者未达门槛。而 C 单独作用时 $\mathrm{cv}_{\mathrm{nn}}$ 为 $-5.44\%$（改善），A1 单独作用时为 $+4.56\%$（劣化）。

三者构成完整的对照链：**组合的表现不但差于较好的一项（C1），也差于较差的一项（A1），即劣于两个单项的任何一个。** 若两项改动的效果可线性叠加，组合的预期应介于 $-5.44\%$ 与 $+4.56\%$ 之间；实测的 $+7.44\%$ 落在该区间之外，说明存在超出简单叠加的负向交互。

此外该 run 的 best epoch 为 **61**，为 9 个论文级 run 中最早，显著早于基线的 147 与 C1 的 93。这提示组合损失下的选择指标在训练早期即达峰随后退化，即组合并非"收益相抵"，而更可能是"优化过程本身被干扰"——两项损失对同一组参数施加了方向冲突的梯度压力，使训练无法在任何一方向上充分收敛。

本文将此列为负面结果如实报告，并严格限定其外推范围：该结论**仅适用于本文所实现的 A 与 C 两项损失在本文所用权重下的组合**，不外推至其他损失项组合、其他权重配置或其他网络结构。本文亦不声称"多损失组合普遍无效"——该断言超出本文实测范围。

### 6.4.3 固定权重和目标比值敏感性（未实验）

本节列出两项本文未完成的敏感性实验及其对结论的影响，不以推测填充。

**固定权重的取值敏感性：未测。** 本文的 B1 采用单一固定值 $w_{\mathrm{adv}} = 8.27$。该值来自 B-001 试跑的实测均值，因此不是任意选取；但本文未测量其他固定值（如 0.827、82.7）下的表现。这带来一项确切的归因局限：**B2 相对 B1 的改善中，来自"动态调整"的部分与来自"权重整体更小"的部分不可分离。** 由第 5 章的 $\hat\rho$ 轨迹，GAAW 在多数 epoch 给出的实际权重远低于 8.27，因此"一个更小的固定值可能达到相近效果"这一竞争解释无法排除。

补足该缺口的实验设计是明确的：以 GAAW 在平台区的实际权重中位数作为新的固定值，重跑一组 B1'，比较 B2 与 B1'。若 B2 仍显著优于 B1'，则动态性本身有价值；若二者无法区分，则本文方法的收益应归因于权重量级而非自适应机制。**该实验未做，因此本文不主张"自适应机制本身"的有效性，只主张"相对 PU-GAN 惯例取值的固定权重有改善"。**

**目标比值 $r_{\mathrm{target}}$ 的敏感性：未测。** 本文取 $r_{\mathrm{target}} = 0.1$，该值使 GAAW 的初始权重与 B1 的固定值同量级。$\pm 50\%$ 扰动下的表现未测量，因此本文无法说明该方法对该超参的鲁棒性。这一缺口的后果是：本文不能声称 GAAW"免于超参调优"——它把一个超参（$w_{\mathrm{adv}}$）替换为另一个超参（$r_{\mathrm{target}}$），而后者的敏感性未知。

### 6.4.4 与通用梯度加权方法的对照（未实验）

GAAW 的梯度范数比思想与两类既有方法相关，本文均未做实测对照，此处说明未做的理由与由此产生的限制。

**VQGAN 式自适应判别权重[116]。** 该方法在图像生成中按重建损失与对抗损失的梯度范数比动态确定判别器权重，与 GAAW 的形式高度相似。本文的写作红线明确禁止声称首次提出该公式（见 `docs/STYLE_GUIDE.md`）。本文与其的差别在于问题域（点云上采样 vs 图像生成）与验证方式（本文给出该场景下的梯度尺度测量与受控消融），而非公式创新。**本文未在点云任务上实现其原始形式作对照**，因此不能声称本文的适配优于直接移植。

**GradNorm[33]。** 该方法面向多任务学习，以任务间训练速率均衡为目标，需引入任务速率作为额外状态量。GAAW 在两分支、角色不对等的设定下不引入该状态量，实现更简单。但**本文未实现 GradNorm 作对照**，因此"更简单"是实现层面的事实陈述，不构成效果层面的优势主张。

两项对照的缺失使本文的方法学定位限于：在点云上采样这一具体场景中，将梯度范数比赋权与该领域通行的固定权重惯例作了受控比较，并给出了该场景下的机制测量。本文不参与"哪种梯度加权方法更优"这一更一般问题的比较。

## 6.5 机制测量与过程分析

### 6.5.1 动态权重与梯度比例轨迹

第 5 章已给出 $\hat\rho$ 的 150 epoch 演化轨迹（图 5.1）及其四项稳健性核验。本节复述与本章裁定相关的读数，并说明其与 6.3.2 节主结果的关系。

**口径 caveat（须与图注同时出现）**：$\bar w_{\mathrm{auto}}$ 为 epoch 内各 batch 的算术平均；$\hat\rho = r_{\mathrm{target}} / \bar w_{\mathrm{auto}}$ 是基于该均值的代表值，**不等于 $\mathrm{mean}(\rho)$**。该量仅可用于数量级演化趋势的刻画，**不可作单 batch 精确值引用**。梯度范数本身未落盘，$\hat\rho$ 由 `history.json` 的 `train_adv_w_adaptive` 字段反解得到。

四项读数如下。其一，$\hat\rho$ 全程极差为 $3.92×10^{6}$ 倍。其二，剔除首尾各 10% 分位后的抗异常点极差为 $4.31×10^{5}$ 倍，剔除首尾各 5% 分位后为 $1.51×10^{6}$ 倍——即该跨度不是由个别离群 epoch 造成。其三，按每 25 个 epoch 分段的中位数依次为 0.0205、30.04、228.20、493.75、1777.94、11623.80，分段 Spearman 相关为 1.0，严格单调递增。其四，平台区中位数为 2212.65，早期中位数为 0.0205，阶段比值 $1.08×10^{5}$ 倍。

由于 $\hat\rho$ 与 $w_{\mathrm{adv}}$ 成反比，$\hat\rho$ 单调上升意味着 GAAW 给出的实际对抗权重在训练过程中单调下降。B1 的固定值 8.27 对应 $\rho_{\mathrm{fixed}} = 0.012092$，在 B2 的 150 个 epoch 中有 **91.3%** 高于该值——即在绝大多数 epoch 中，GAAW 给出的权重低于 8.27。

**该轨迹与主结果的关系。** 结合 6.3.1 节"固定权重对抗训练损害主指标"这一事实，一个与全部实测方向一致的解释是：8.27 这一取值对本文的生成器而言偏大，GAAW 通过按梯度范数比自动压低权重，减少了对抗分支对重建目标的干扰，从而使主指标的劣化幅度减半。

**但该解释存在一个本文无法排除的竞争解释**，即 6.4.3 节所述：收益可能仅来自"权重更小"而非"动态调整"。本文的轨迹证据能够说明 GAAW 确实做了非平凡的动态调整（H1、H4 成立），但不能说明该动态性是收益的来源。这一区分是本文机制论述的确切边界。

### 6.5.2 逐样本配对差值与局部稀疏分层

均值差异只回答"平均而言是否更好"，不回答"是否在多数样本上都更好"。两者可以分离：一个由少数样本的大幅改善拉动的均值，与一个在绝大多数样本上一致小幅改善的均值，在均值层面可能相同，但方法可靠性含义完全不同。本节因此报告逐样本配对的改善占比。

该量的性质须先说明：它是**事实陈述而非假设检验**。"200 个样本中有多少个方向变好"是可直接清点的计数，本文未对其设定接收门槛，也不作显著性裁定。B1 与 B2 使用同一机器、同一批次、同一组 200 个验证样本，按样本索引严格配对（索引集合完全一致已核验，脚本 `scripts/paired_improvement.py`，结果落盘 `docs/_paired_improvement_B2_vs_B1.json`）。

**表 6.5  B2（GAAW）相对 B1（固定权重）的逐样本配对改善占比（$n=200$）**

| 指标 | 改善样本数 | 变差样本数 | 改善占比 | 配对差值中位数 |
|---|---|---|---|---|
| $\mathrm{cv}_{\mathrm{nn}}$ | **158** | 42 | **79.00\%** | $-1.7194×10^{-2}$ |
| CD | 131 | 69 | 65.50\% | $-1.9463×10^{-5}$ |
| HD | 106 | 94 | 53.00\% | $-1.2686×10^{-4}$ |

表注：配对差值以 B2 减 B1 计，负值表示 B2 更优；三项指标均越小越好。无持平样本。数据来源 `docs/_paired_improvement_B2_vs_B1.json`。

三项结果的读法各不相同，须分别陈述。

**$\mathrm{cv}_{\mathrm{nn}}$：79.00\% 的样本改善**，即约每五个样本中有四个变好。该占比与 6.3.2 节均值层面的 ACCEPT 裁定方向一致，且进一步表明该改善不是由少数样本的极端增益拉动的均值假象，而是在样本总体上普遍出现。

**CD：65.50\% 的样本改善。** 此处出现一项须如实说明的现象：CD 在均值层面未达门槛（$0.32\,\mathrm{SE}$，判 `REJECT_NULL`），但在配对计数层面呈现约 2:1 的多数。二者不矛盾，其成因是两个层面的噪声结构不同——均值比较承受了样本间固有的量级差异（不同形状的 CD 绝对值本身相差数倍），而配对计数只看同一样本上的方向，样本间差异被抵消。

**但本文不因此改判 CD 的有效性。** 6.3.2 节的裁定依据是实验前定死的均值门槛，本节的配对计数是在结果已知之后追加的分析视角。若在看到配对结果有利之后改用配对口径重新裁定，即构成按结果选择判据，其性质与事后放宽门槛相同。故本文的处理是：**CD 的有效性主张仍不作出**，配对占比仅作为描述性补充信息报告，供读者自行判断。本文亦不在此处引入配对标准误重算显著性，理由同上。

**HD：53.00\% 的样本改善**，即改善与变差样本数接近各半（106 对 94）。该结果与 6.3.2 节 HD 未达门槛（$0.35\,\mathrm{SE}$）的裁定完全一致，并为其提供了更直观的解释：HD 上的方向性差异在样本层面近乎随机，均值上的 $-1.69\%$ 主要来自个别样本的波动而非普遍趋势。本文因此明确，**HD 维度不存在可主张的改善**。

综合三项，本节的结论是：GAAW 的作用在均匀性维度上普遍且方向一致（79.00\%），在几何保真度维度上呈多数倾向但不作有效性主张（65.50\%），在最坏区域风险维度上与随机无异（53.00\%）。三者不可合并表述为"全面改善"。

**尾部质量的分位对照。** 以每样本 $\mathrm{cv}_{\mathrm{nn}}$ 的第四四分位均值与第一四分位均值之比 $Q_4/Q_1$ 衡量样本间质量落差：B1 为 1.629584，B2 为 1.625657，差异 $-0.24\%$。该量表明 GAAW 在改善均匀性的同时**既未扩大也未缩小样本间的质量落差**，即改善并非以牺牲部分样本为代价。此项同为描述性统计，本文未对其设定接收门槛，故不作显著性裁定。

## 6.6 训练代价与可复现性

### 6.6.1 训练时间、显存和额外反向传播开销

**本节报告本文方法的真实代价。** 只报指标改善而不报计算开销，读者无法判断方法是否值得采用；GAAW 每步需对两个损失分支分别调用 `autograd.grad` 以取梯度范数，这是一整轮额外反传，其代价必须量化。

数据口径（跑前定死，记录于 `docs/_train_cost.json` 的 `caliber` 字段）：时间取逐 epoch `sec` 字段的**中位数**而非均值，因首个 epoch 含 CUDA 上下文初始化与 cuDNN autotune 而系统性偏高（B2 首 epoch 164.51 s），均值会被单点异常拉偏；显存取全程 `gpu_peak_gb` 的**最大值**；相对开销只在同机器内计算，因不同 GPU 的绝对耗时不可比。

### 6.6.2 多随机种子重复与跨运行不确定性（未实验）

**本文全部 9 个论文级 run 均使用单一随机种子 20260811。** 因此本文无法给出任何结论的跨种子方差，6.1.3 节的 $\mathrm{SE}$ 一律为跨样本标准误。

本文不以"未测"的方式为该项留出解释空间，而是明确：**凡涉及跨种子可复现性的主张，本文一概不作。** 这同时限定了第 5 章 H1 的适用范围——H1 确立的是"在 `ABL_B2_adv_adaptive` 这一次 150 epoch 训练内梯度范数比非平稳"，而非该机制在任意初始化下必然呈现同一量级的演化。

该缺口对本文主结论的影响需要具体评估，不宜笼统带过。主对比的 $\mathrm{cv}_{\mathrm{nn}}$ 效应量为 8.48 倍跨样本标准误，且逐样本配对显示 79.00\% 的样本方向一致；这两项证据共同降低了"该差异纯由样本选择偶然性造成"的可能性，但**无法排除"该差异由这一次训练的初始化偶然性造成"**。后者只能由多种子重复实验排除。因此本文主结论的正确表述是"在本次受控运行中观察到"，而非"该方法稳定优于对照"。

补足该缺口的实验设计是清楚的：对 B1 与 B2 各重复 3 至 5 个种子，以跨种子标准误重新裁定。本文未做的原因是计算资源约束（由表 6.7，B1 与 B2 各一次 150 epoch 训练合计约 10.7 小时，5 种子重复需约 53 小时）。该实验列为首要后续工作。

## 6.7 结果讨论

### 6.7.1 获得支持、未获支持与待验证的假设

第 4 章预注册了五条可验证假设，其接收条件在实验前固定。本节逐条给出裁定，并明确各条之间的逻辑关系。

**表 6.9  预注册假设的逐条裁定**

| 假设 | 接收条件 | 实测 | 裁定 |
|---|---|---|---|
| H1 机制存在性 | $\hat\rho$ 极差 $\geq 100$ 倍 | $3.92×10^{6}$ 倍（抗异常点 $4.31×10^{5}$ 倍，分段单调 Spearman $=1.0$） | **成立** |
| H2 CD 改善 | $\Delta\mathrm{CD} \leq -2\,\mathrm{SE}$ | $0.32\,\mathrm{SE}$ | **不成立** |
| H3 $\mathrm{cv}_{\mathrm{nn}}$ 改善 | $\Delta\mathrm{cv}_{\mathrm{nn}} \leq -2\,\mathrm{SE}$ | $8.48\,\mathrm{SE}$ | **成立** |
| H4 机制可解释性 | B1 固定值偏离占比 $\geq 70\%$ | $91.3\%$ | **成立** |
| H5 诚实报告（执行性） | 据实报告 B2 vs B0 各指标 | 6.3.3 节已报告（$\mathrm{cv}_{\mathrm{nn}}$ $+7.47\%$ 反向显著） | **履行** |

**四条成立、一条不成立。** 按第 4 章"H1–H5 逐条独立"的总判定规则，H2 的失败不否定其余各条：H1 与 H4 验证机制本身被触发，H3 验证机制在主指标上带来改善，H5 验证对照纪律被执行，四者与 H2 无逻辑蕴涵关系。

**但须避免一处误读。** H1、H4 成立说明"GAAW 确实做了非平凡的动态调整"，H3 成立说明"B2 的主指标优于 B1"，两者的合取**不等于**"该改善由动态调整造成"。这两个命题之间缺失的一环正是 6.4.3 节所述的竞争解释：一个更小的固定权重可能达到相近效果，而该对照实验本文未做。因此本文机制论述的确切强度是：**机制被触发（已证），主指标改善（已证），二者之间的因果链条（未证）。**

**待验证项汇总。** 以下四项本文未做，其缺失对结论的影响已在各节说明：固定权重取值敏感性（6.4.3）、$r_{\mathrm{target}}$ 敏感性（6.4.3）、与 VQGAN／GradNorm 的实测对照（6.4.4）、多随机种子重复（6.6.2）。其中第一项与第四项直接限制本文主结论的强度，列为首要后续工作。

### 6.7.2 失败案例和适用边界

本节汇总本文实测中的失败案例，并据此界定方法的适用边界。失败案例与成功案例同等报告，因前者对边界的界定作用不可替代。

**失败案例一：A 系双向 Chamfer 加权（6.4.1 节）。** 温和与激进两档加权均使主指标劣化且呈单调关系。该案例的边界含义是：均匀性缺陷不能通过重新分配既有重建损失的内部权重来修正。

**失败案例二：AC 组合倒赔（6.4.2 节）。** 分别有效的 C1 与无效的 A1 组合后，表现劣于两个单项中的任何一个，且 best epoch 提前至 61。该案例的边界含义是：损失项的效果不可假定线性叠加，多项组合须单独验证。

**失败案例三：D1 注意力缩放（6.4.2 节）。** 补上标准做法后三项指标同时崩塌。该案例的边界含义是：复现所得的超参配置与实现细节相互耦合，单点修改可能使整体配置失效；本文对基线的任何"缺陷"判断都须先排除该耦合。

**失败案例四：对抗分支本身损害主指标（6.3.1 节）。** B1 相对 B0 的主指标劣化 $14.86\%$。该案例的边界含义最为重要：**本文方法的适用前提是"已决定采用对抗训练"**，若使用者尚未决定，本文的实测结果不支持引入对抗分支。

**适用边界的正面表述。** 综合上述，本文方法的适用条件为：（1）任务为固定倍率（本文 $r=4$）的点云 patch 上采样；（2）技术选型中已包含对抗训练；（3）关注指标为局部间距均匀性；（4）可承受训练期约 $70\%$ 的额外时间开销；（5）不要求跨随机种子的稳健性保证。五项条件同时满足时，本文的实测结果支持采用 GAAW 替代固定权重赋权。

**不适用的场景。** 若技术选型不含对抗训练，则 C1（显式均匀性损失）是本文实测中代价更低且同样有效的方案；若关注指标为几何保真度（CD）或最坏区域风险（HD），本文实测未观察到可主张的改善；若需要跨种子稳健性保证，本文的证据不足。

**不可外推的范围。** 本文的全部结论限定在：PU1K 数据集、patch 形式、$N=256$、$r=4$、单一随机种子、本文所实现的网络与损失形式。本文不就其他数据集、其他倍率、任意倍率方法、其他骨干网络或其他梯度加权方法作任何主张。

### 6.7.3 对本文初衷的回答

第 1 章以一组连续追问提出问题。本节逐条回答，凡未获实测支持者明确说明。

**问：低 Chamfer 距离是否等于高质量点分布？** 答：不等于。6.2.2 节的实测给出直接证据——基线在 CD 上已进入平台，而其输出的最近邻间距离散度为真值的 4.22 倍；200 样本上 $\mathrm{cv}_{\mathrm{nn}}$ 与 CD 的秩相关仅 $-0.217$，即 CD 的高低几乎不携带均匀性信息。因此以 CD 为唯一优化目标与评价指标，会系统性地遗漏均匀性缺陷。

**问：对抗监督为什么可能补足集合距离的盲区？** 答：其理据是对抗损失提供分布级监督，不依赖逐点对应，因而原则上可约束集合距离无法表达的分布性质。**但本文的实测不支持该理据在本文配置下成立**：6.3.1 节显示引入固定权重对抗分支后主指标劣化 $14.86\%$。即"原则上可以补足"与"在本文实现中确实补足"是两个不同命题，后者在本文中为否。本文对此如实报告，不以理据代替实测。

**问：固定权重为什么可能随训练失配？** 答：6.5.1 节给出该失配的直接测量——两分支梯度范数比在 150 个 epoch 内跨越 $3.92×10^{6}$ 倍且分段中位数严格单调递增，而固定权重按定义不随之变化。B1 的固定值在 B2 的 $91.3\%$ 的 epoch 中偏离实际梯度环境。该测量是本文最确切的一项贡献：它把"固定权重可能失配"这一推测转化为该场景下的量化事实。

**问：动态权重究竟要解决"有没有对抗"还是"对抗贡献多大"的问题？** 答：本文的实测明确了这一区分，且答案对本文方法构成限制。GAAW 只解决后者——6.3.2 节显示其在"已引入对抗分支"的前提下使主指标改善 $6.43\%$；而 6.3.3 节显示它不解决前者，B2 相对无对抗基线仍劣化 $7.47\%$。**因此本文的方法定位是"对抗贡献多大"这一问题的一个答案，而非"是否需要对抗"这一问题的答案。** 后一问题在本文实测中的答案是否定的，本文不回避该结论。

**综合回答。** 本文的初衷是理解"为什么低 CD 不等于高质量输出，以及辅助监督应如何配置"。经本章实测，可获支持的回答是：CD 与均匀性确为两个近乎独立的维度（已证）；固定权重的对抗监督在本文配置下不改善均匀性（已证）；在采用对抗监督的前提下，按梯度范数比动态赋权优于固定赋权（已证）；而该改善是否源于动态性本身（未证）、是否跨种子稳定（未证）、是否优于更简单的显式均匀性约束（实测显示后者性价比更高）。本文以这一组"已证与未证"的划分作为对初衷的回答，不作超出证据的推论。

## 6.8 本章小结

本章在 $n = 200$ 的同口径验证子集上报告了 9 个论文级 run 的实测结果，主要结论如下。

**其一，本文方法的核心主张获得实测支持且限定明确。** GAAW（B2）相对固定权重对抗训练（B1）在主指标 $\mathrm{cv}_{\mathrm{nn}}$ 上改善 $6.43\%$，达跨样本标准误的 8.48 倍，H3 成立；逐样本配对进一步显示 200 个样本中 158 个（$79.00\%$）方向变好，该改善在样本总体上普遍出现而非由少数极端样本拉动。同时 CD 与 HD 的点估计方向同为改善（$-1.36\%$、$-1.69\%$），即该改善未以几何保真度或最坏区域风险为代价；但二者偏移量仅为 $0.32\,\mathrm{SE}$ 与 $0.35\,\mathrm{SE}$，低于实验前设定的门槛，故本文不对 CD 与 HD 作有效性主张，H2 不成立。

**其二，对抗训练本身在本文实现下损害主指标。** B1、B2 相对无对抗基线的 $\mathrm{cv}_{\mathrm{nn}}$ 分别上升 $14.86\%$ 与 $7.47\%$，均为反向显著。本文的主张严格限定为"若采用对抗训练，则梯度自适应赋权优于固定权重"，不主张对抗训练优于不用对抗训练。

**其三，机制被触发已证，但机制与收益之间的因果链未证。** $\hat\rho$ 在 150 个 epoch 内跨越 $3.92×10^{6}$ 倍、抗异常点极差 $4.31×10^{5}$ 倍、分段中位数严格单调，B1 固定值在 $91.3\%$ 的 epoch 中偏离实际梯度环境，H1 与 H4 成立。但本文未设置"更小的固定权重"对照组，故无法排除收益仅来自权重量级而非动态性这一竞争解释。

**其四，显式均匀性约束 C1 是本文实测中性价比最高的方案。** 其主指标改善 $-5.44\%$，CD 与 HD 变化均未达门槛，训练开销仅 $+13.04\%$，无额外参数。相比之下 GAAW 需 $+70.58\%$ 的额外训练时间与 255426 个判别器参数。本文如实报告该对照，并将自身方法的适用范围限定在"已采用对抗训练"这一前提内；二者的组合效果本文未测。

**其五，三项负面结果与一项排除性实验如实报告。** A 系双向 CD 加权无法替代显式均匀性约束且加权越激进劣化越严重；A 与 C 的组合出现倒赔且 best epoch 提前至 61；D1 的 $1/\sqrt{d}$ 缩放在未重调超参条件下导致三项指标崩塌，定位为排除性实验而非改进点。

**其六，本章的报告边界已显式列出。** 跨种子稳健性不报告、P2F 不可测、与已发表方法的横向绝对值不对表、跨机器绝对值不并列、固定权重与 $r_{\mathrm{target}}$ 敏感性未测、与 VQGAN／GradNorm 的实测对照未做。本文的全部有效性结论限定在本文内部同口径消融对照的范围内。

**其七，训练代价已量化。** GAAW 相对固定权重的额外训练时间为 $+70.58\%$、峰值显存为 $+7.98\%$，来源是每步两次额外的 `autograd.grad` 调用与 `retain_graph=True` 造成的激活保留。该开销仅存在于训练期，推理期计算量与无对抗基线完全一致。

下一章在这些结论与边界的基础上给出全文总结与后续工作方向，不引入任何新的实验结果。
