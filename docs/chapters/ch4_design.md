# 第4章 模型假设与研究设计

本章把第 3 章定位的瓶颈转化为可证伪的命题。所谓可证伪，要求在观察结果之前就把三件事固定下来：作为判断依据的观测量、被判定为“改善”的方向，以及区分真实效应与样本波动的门槛。本章依次给出变量定义、对照结构、假设及其接收条件与统计判定的效力边界，但不给出任何实测数值——凡涉及裁定的结果一律留待第 6 章。

这一安排针对的是实证研究中一类常见的推断风险：当判据可以在看到结果之后再行选择时，即便方法本身无效，研究者也总能从多个候选指标、多个对照组或多个显著性口径中找出一组使结论成立的组合。此时报告出的“显著性”度量的是选择自由度而非效应本身。本章通过在实验执行前固定假设与判据、并在第 6 章原样执行，把这一自由度从推断链条中移除；其代价是本文必须接受部分预设命题被实测否定，第 6 章确有一条假设未获支持，本文按判据如实裁定而未作调整。

## 4.1 重建—对抗梯度关系的作用机制分析

### 4.1.1 研究问题与可证伪假设

第 3 章的诊断给出三项事实：输出点云的最近邻间距变异系数为真值的 4.22 倍而平均间距比值为 0.916；误差随输入局部稀疏度单调上升，最疏与最密四分位比为 1.476；双向 Chamfer 的后向分量在训练全程持续占优。第三项事实同时伴随一项相关性观测——$\mathrm{cv}_{\mathrm{nn}}$ 与 CD 的秩相关仅 $-0.217$，即压低 CD 不改善均匀性。

这组事实把问题定位到"重建损失之外需要何种辅助监督"。对抗损失是候选之一，其理据是提供不依赖逐点对应的分布级监督[13]。但对抗损失的引入带来一个本文关注的具体问题：**其权重应如何给定**。领域惯例是取常数[64]，而第 3.3.2 节的梯度尺度实测表明对抗分支与重建分支的梯度量级相差约两个数量级，且该关系是否随训练稳定未经测量。

对抗训练的稳定性本身是一个受到持续关注的问题，既有工作从损失形式[28,35]、更新时序[36]与收敛性分析[47]等角度提出了多种改善手段。**本文不涉及这些方向**：本文固定 hinge 损失形式与每步各更新一次的时序，只改动生成器侧两个损失分支的相对权重。因此本文的工作与上述稳定化技术互不替代，亦未测量二者的交互。

由此形成本章的核心研究问题：

> 在点云上采样的对抗—重建两分支训练中，对抗损失权重按两分支梯度范数比动态给定，相对按领域惯例取常数，是否带来可归因的指标改善？

该问题被分解为五条可证伪假设。每条假设指定对照组、指标、方向、统计单位与失败后的处理方式。**假设不是预先写好的结论**——本章明确列出每条失败时论文须如何修改表述。

**H1（梯度范数动态的实证存在性）**

- 命题：GAAW 在 150 epoch 训练中给出的 $w_{\mathrm{adv}}$ 取值非平凡，即两分支梯度范数比 $\hat\rho$ 的跨 epoch 极差超过两个数量级。
- 对照组：无（该假设为单组轨迹的性质检验）。
- 指标与统计单位：$\hat\rho$ 的逐 epoch 值，$n = 150$。
- 接收条件：$\hat\rho_{\max} / \hat\rho_{\min} \geq 100$。
- 失败后的处理：若 $\hat\rho$ 近似恒定，则 GAAW 退化为固定权重的等价形式，本文的机制论述失去基础，H2、H3、H4 全部失去解释依据，论文须将 GAAW 降级为一种权重取值方法而非机制贡献。

**H2（相对固定权重对照的 CD 改善）**

- 命题：B2 相对 B1 在 CD 上更优。
- 对照组：B1（$w_{\mathrm{adv}} = 8.27$ 固定），同机器同种子。
- 指标与统计单位：推理期逐样本 CD 的均值，$n = 200$。
- 接收条件：$\Delta\mathrm{CD} \leq -2\,\mathrm{SE}$，$\Delta$ 以 B2 减 B1 计。
- 失败后的处理：不对 CD 作有效性主张，明确写出"CD 维度的改善未获实测支持"，不以"方向向好"替代。

**H3（相对固定权重对照的 $\mathrm{cv}_{\mathrm{nn}}$ 改善）**

- 命题：B2 相对 B1 在主指标上更优。
- 对照组：B1，同机器同种子。
- 指标与统计单位：推理期逐样本 $\mathrm{cv}_{\mathrm{nn}}$ 的均值，$n = 200$。
- 接收条件：$\Delta\mathrm{cv}_{\mathrm{nn}} \leq -2\,\mathrm{SE}$。
- 失败后的处理：本文的核心主张不成立，GAAW 应作为"机制存在但未带来收益"的负面结果报告，论文的贡献表述须相应缩减为纯测量工作。

**H4（机制与对照差异的一致性）**

- 命题：B1 的固定权重在多数 epoch 中偏离 B2 的实际权重一个量级以上。
- 对照组：B1 的固定值与 B2 的逐 epoch 实际值。
- 指标与统计单位：偏离 epoch 的占比，$n = 150$。
- 接收条件：占比 $\geq 70\%$。
- 失败后的处理：若固定值与动态值大部分时间接近，则两组的行为差异缺少机制解释，H2、H3 若成立亦无法归因于赋权方式，须寻找其他解释。

**H5（相对无对抗基线的诚实报告）**

- 命题：本假设不预设方向。B2 相对无对抗基线**不一定更优**。
- 对照组：B0（无对抗基线），同机器同种子。
- 性质：**执行性条件而非有效性条件**。
- 接收条件：据实报告 B2 相对 B0 的三项指标，凡反向变化者不得省略或淡化。
- 失败后的处理：该项失败即意味着论文违反报告纪律，属写作层面的失效而非方法层面的失效。

**五条假设的逻辑关系须预先明确，以防第 6 章的裁定被误读。** H1 与 H4 检验机制是否被触发；H2 与 H3 检验机制是否带来收益；H5 检验报告纪律。三组之间无逻辑蕴涵：H1、H4 成立不保证 H2、H3 成立；H2 或 H3 单条失败不否定 H1、H4。唯一的单向依赖是 H1 失败会使其余各条失去解释基础。

**一项本章即须声明的归因局限。** 即使 H1、H3、H4 全部成立，其合取仍不足以证明"改善由动态调整造成"。理由是：若 GAAW 给出的权重系统性地低于 B1 的固定值，则"一个更小的固定权重可能达到相近效果"这一竞争解释无法排除。排除该解释需要第三个对照组（以 GAAW 实际权重的代表值作为新固定值），本文因资源约束未设置该组。**本章在此显式声明该局限，以免第 6 章的机制论述被读作因果确证。**

### 4.1.2 变量测量

本节定义全部变量及其测量方式，使第 6 章的每项对照都可核查其是否满足单一变量约束。

**自变量（四个水平）。** 辅助监督的配置方式，取四个离散水平：（1）无辅助项，$w_{\mathrm{adv}} = 0$、$w_{\mathrm{unif}} = 0$；（2）固定对抗权重，$w_{\mathrm{adv}} = 8.27$；（3）梯度自适应对抗权重，由 GAAW 按式给定；（4）显式均匀性约束，$w_{\mathrm{unif}} = 0.00191$。第四个水平的作用是竞争基线——若一个更简单的方案达到相近效果，本文方法的价值须相应限定，故该水平必须进入主表而非作为附录消融。

**因变量（五项）。** 主指标为 $\mathrm{cv}_{\mathrm{nn}}$（输出点云内部最近邻间距的变异系数），选定理由是它直接度量第 3 章定位的瓶颈，且无需预设邻域半径。同报指标为 CD（平均几何保真度）与 HD（最坏区域风险）。分层指标为 $Q_4/Q_1$，即按输入局部稀疏度分位的后向 Chamfer 分量之比，其作用是鉴别改进的作用位置。代价指标为训练时间与峰值显存。

不以 CD 为主指标的理由有两层。其一是本文自身的实测：第 3.5.2 节测得 200 样本上 $\mathrm{cv}_{\mathrm{nn}}$ 与 CD 的秩相关仅 $-0.217$，即 CD 的高低几乎不携带均匀性信息。其二是既有工作对 Chamfer 距离的分析：其均值形式对局部密度差异的惩罚被稀释，因而存在对分布缺陷不敏感的盲区，相应的密度感知改进形式已被提出[93]。两层依据方向一致，故本文以直接度量瓶颈的 $\mathrm{cv}_{\mathrm{nn}}$ 为主指标，而将 CD 作为同报项以监测保真度是否被牺牲。

五项因变量不可互相替代，理由由第 3.4.4 节的极端对照标定给出：各指标的盲区互不重叠，均匀性完全退化的构型在 P2F 上与理想构型同量级。因此任一单项指标的改善不足以支持整体质量提升的结论。

**控制变量。** 全部消融组共享：数据集与划分（PU1K，验证区间 $[65550,69000)$）、随机种子（20260811）、`batch_size`（64）、`epochs`（150）、优化器与学习率调度、梯度裁剪[9]阈值、输入规模（$N = 256$）与上采样率（$r = 4$）、生成器结构与参数量（1152803）。

生成器参数量恒定这一约束值得单独说明其作用：它使"改善来自模型容量增加"这一混杂解释被结构性排除，因此本文无需设置"同等参数量朴素扩容"的对照组。第 3.5.5 节曾要求该对照，本章据此判定该要求已被参数量恒定这一更强的约束自动满足。

**机制变量。** 两分支梯度范数 $g_{\mathrm{cd}}$ 与 $g_{\mathrm{adv}}$ 及其比值，以及由该比值导出的逐 epoch 动态权重。该组变量的作用是提供机制证据而非性能证据——它回答"机制是否被触发"，不回答"触发后是否有效"。

**测量口径的两项限定。** 其一，梯度范数本身未落盘，机制变量由训练期监控字段反解得到，因此其口径为 epoch 内批次的算术平均导出值，仅可用于数量级趋势刻画。其二，$\mathrm{cv}_{\mathrm{nn}}$、CD、HD 三项因变量取自各 run 的 `best.pt` 检查点在验证子集上的推理结果，与训练期的逐 epoch 监控量口径不同，二者的离散度统计不可合并。

## 4.2 梯度自适应权重影响因素分析

### 4.2.1 影响因素的识别

在设计对照之前须识别可能影响结果的因素，否则单一变量约束无法落实。本节逐项列出并说明本文的处理。

**因素一：参数作用域。** 梯度范数在哪些参数上计算。本文取生成器全部参数，与 VQGAN 在图像生成中对解码器最后一层取范数[116]的做法不同。取全参数的理由是本文的生成器不存在天然的"最后一层"（坐标回归头维度极小，其梯度范数不足以代表整体）。该选择带来的后果是计算开销较高，代价在第 5.4 节量化。**本文未测量其他作用域下的表现**，因此不声称全参数作用域是最优选择。

**因素二：目标比值 $r_{\mathrm{target}}$。** 决定对抗梯度相对重建梯度的目标占比。本文取 0.1，取值依据是使 GAAW 的初始权重与领域惯例的固定值同量级，从而使两组的起点可比。该值的敏感性未测（见 4.3.3 节效度威胁）。

**因素三：数值稳定项 $\epsilon$。** 防止分母为零。本文取 $10^{-8}$。该量级相对实测梯度范数足够小，不构成实质影响。

**因素四：warmup 调度。** 训练初期梯度范数估计不稳定，本文按线性递增系数调制权重幅值（epoch 0 为 0.1，epoch 30 达 1.0）。**该因素须特别说明其与 GAAW 的正交性**：warmup 对固定权重与动态权重同样施加，因此它不构成两组之间的差异来源。若 B1 与 B2 的差异被归因于 warmup，该解释不成立——两组的 warmup 配置完全一致。

**因素五：固定权重的取值。** B1 取 8.27。该值来自 B-001 试跑中对抗权重训练期监控量的实测均值，而非任意选取。这一点是 B1 作为对照组能够成立的前提：若取一个随手选定的值，则"GAAW 优于该值"不构成有意义的结论。但本文只覆盖单一取值，由此产生的归因局限已在 4.1.1 节声明。

**因素六：判别器更新频率。** 本文取生成器与判别器每步各更新一次，两组一致。判别器更新时不引用 GAAW 给出的权重，该隔离设计避免判别器侧的对抗强度与 GAAW 直接耦合。本文未测量其他更新比例（如 $n_{\mathrm{critic}} > 1$）下的表现。

**因素识别的结论**：六项因素中，因素二、五、六为本文未覆盖的取值维度，构成第 6.4.3 节与第 7.3.2 节所列的敏感性缺口；因素一、三、四为已固定且两组一致，不构成组间差异来源；其中因素四的正交性使一类常见的替代解释被结构性排除。

### 4.2.2 研究假设的提出与其预期失败模式

4.1.1 节已给出 H1–H5 的完整定义。本节补充说明每条假设在实验前的先验强度，以及本章为何不预设其成立。

**H1 的先验较强但非确定。** 第 3.3.2 节已实测两分支梯度量级相差约两个数量级，因此"比值非恒定"有先验支持。但该实测为单点观测，未涵盖训练全程；比值可能在训练早期剧烈变化而后趋稳，此时极差虽大但"动态调整"的实际作用区间有限。因此本章对 H1 追加一项要求：**极差不得由个别离群 epoch 造成**，须补充抗异常点统计与分段单调性核验。该要求写入本章即固定，不留待结果出来后追加。

**H2 与 H3 的先验弱。** 本文没有理由预期动态赋权必然改善 CD 或 $\mathrm{cv}_{\mathrm{nn}}$。相反，第 3 章的诊断表明 CD 与均匀性近乎独立（秩相关 $-0.217$），因此**两项同时改善的先验概率低**。本章明确预期：两项中至多一项可能通过门槛，且更可能是 $\mathrm{cv}_{\mathrm{nn}}$——因为对抗损失作用于分布层面，与均匀性的关联比与平均保真度的关联更直接。该预期写入本章，其作用是使第 6 章"H2 不成立而 H3 成立"这一结果不显得像事后解释。

**H4 的先验中等。** 若 H1 成立（比值跨数量级变化），则固定值在多数 epoch 偏离实际值几乎是算术后果。因此 H4 的信息量低于 H1，其作用是把 H1 的"比值变化"转化为"与对照组的具体差异"，使机制解释与对照实验建立连接。

**H5 不预设方向，且本章预期其方向不利。** 第 3.3.2 节的梯度尺度实测显示对抗梯度远小于重建梯度，而固定权重 8.27 使其有效贡献被放大约两个数量级。在均匀性缺陷尚未由显式约束处理的情况下，放大分布级监督可能挤压重建目标，从而抬高 $\mathrm{cv}_{\mathrm{nn}}$。**因此本章预期 B1 相对 B0 在主指标上劣化，且 B2 相对 B0 亦可能劣化。** 该预期写入本章的目的是：若第 6 章确实观测到该劣化，其报告不构成"事后补救"，而是预期内的结果；同时它提前限定了本文方法主张的形式——只能主张"在采用对抗训练的前提下更优"，不能主张"优于不采用对抗训练"。

## 4.3 理论模型和检验设计

### 4.3.1 对照组、随机种子与实验批次

**三层对照结构。** 本文设置三层对照，逐层回答不同问题，不可互相替代。

第一层 B0（无对抗基线）回答"不引入任何辅助项时系统处于什么水平"。第二层 B1（固定权重对抗训练）回答"引入对抗分支的效果"。第三层 B2（GAAW）回答"给定对抗分支后，赋权方式的效果"。

**本文主对比为 B1→B2，而非 B0→B2。** 该选择的依据是命题匹配：本文的命题是"权重应如何给定"，而非"是否应引入对抗分支"。若以 B0 为对照，测得的差值同时包含"引入对抗分支"与"权重如何给定"两项效应，无法归因到本文的机制贡献。

此处须记录一项对第 3.5.5 节预注册的修订。第 3.5.5 节最初指定的对照为无对抗基线，其前提是把改进视为"是否引入辅助项"这一问题。本章依上述命题匹配的理由将主对照修订为 B1，**同时保留原预注册口径的报告**：B2 相对 B0 的裁定按原判据执行并如实报告（即 H5）。两种口径并存而非替换，读者可分别核查。

**竞争基线 C1。** 显式均匀性约束作为第四个自变量水平进入主表。设置该组的理由是：若一个更简单的方案（无判别器、无额外反传、无新增参数）达到相近效果，则本文方法的价值须相应限定。本章预先规定 C1 的结果无论是否有利于本文方法**均须进入主表**，不得移入附录。

**随机种子与实验批次。** 全部 run 使用单一种子 20260811。该配置的效度后果在 4.3.3 节讨论。实验分两个批次执行于两台设备：均匀性与结构消融批次（含 B0-3090、A1、A2、C1、AC、D1）运行于 RTX 3090；对抗赋权批次（含 B0-5090、B1、B2）运行于 RTX 5090。

**跨批次不并列的约束。** 两批次的软件栈版本不同，浮点累加次序差异足以在指标第三位有效数字上产生偏移，而本文若干效应量与该偏移量级可比。因此本章规定：**同一张表内不并列跨机器数字，3090 组只与 B0-3090 对照，5090 组只与 B0-5090 对照**。该约束落盘于 `docs/_thesis_results.json` 的 `redline` 字段，第 6 章每张表的表注重申。

该约束的一项直接后果须提前指出：C1 与 B2 分处不同批次，因此**二者的组合效果无法从现有数据推断**，须另行实验。这构成第 7.4.3 节所列的后续工作。

### 4.3.2 统计单位、配对比较与不确定性口径

**统计单位为验证样本。** 全部因变量的统计单位是验证子集内的单个样本，$n = 200$。该样本以固定种子从验证区间 $[65550, 69000)$ 抽取，抽样索引的落域已核验。

**标准误的口径与其效力边界。** 本文的 $\mathrm{SE}$ 为跨样本标准误，由 200 个样本的样本间波动算得，两组比较时取合并值 $\sqrt{\mathrm{SE}_1^2 + \mathrm{SE}_2^2}$。

该口径回答的问题是：**在这 200 个样本上观察到的组间差异，是否可能仅由样本选择的偶然性造成。** 它**不**回答：换一个随机种子重训，该差异是否仍然出现。后者需要跨种子标准误，而本文为单种子设计，无法给出。

本章据此规定全文的表述纪律：凡本文写"改善"，其完整含义是"在这 200 个验证样本上方向一致，且幅度超过样本波动的 2 倍"；**全文不使用"统计显著"这一表述**，因为该词在通常语境下隐含跨重复实验的稳定性，而本文的证据不支持该含义。

**判定门槛。** 本章在实验前固定三档裁定：$\Delta \leq -2\,\mathrm{SE}$ 判 `ACCEPT`；$|\Delta| < 2\,\mathrm{SE}$ 判 `REJECT_NULL`（在当前样本量下无法与零区分）；$\Delta \geq +2\,\mathrm{SE}$ 判 `REVERSE_SIGNIFICANT`（反向显著）。

**关于三个裁定标签的写法。** 本文全文保留 `ACCEPT`、`REJECT_NULL`、`REVERSE_SIGNIFICANT` 三个英文标签而不译为中文，理由有二。其一，它们是**预注册判据的枚举值**而非叙述性用语：其取值在实验前即已固定，实验后由脚本按上式直接判出并写入存档文件 `docs/_thesis_results.json` 的 `verdict` 字段，正文中的每一处裁定均须与该字段逐字一致（该一致性由 `scripts/audit_thesis_numbers.py` 的裁定通道自动核验）。若改用中文，"接受／接收／成立"等近义写法极易在不同章节间出现漂移，而枚举值的唯一性正是其可核查性的基础。其二，全篇中文行文中的英文标签具有视觉标识作用，读者可一眼区分"由判据机器判出的结论"与"作者的叙述性评价"，这一区分对本文强调的"判据不可事后修改"具有直接作用。三个标签的中文含义分别为：`ACCEPT` 表示相对对照组的改善达到预设门槛而被接受；`REJECT_NULL` 表示偏移量小于门槛、在当前样本量下无法与零区分，**本文一律不据此宣称有效**；`REVERSE_SIGNIFICANT` 表示变化方向与预期相反且达到门槛，即反向显著。该写法约定同时登记于 `docs/STYLE_GUIDE.md` 的术语表。

$2\,\mathrm{SE}$ 这一倍数是本文自设而非领域通行标准。正因其自设，其作用是**约束本文自身**：实验前定死，结果出来后无论有利与否均不改动。本章预先声明：若某项指标的偏移量落在门槛之下，第 6 章一律判 `REJECT_NULL`，不以"趋势向好""接近显著"等表述替代，不放宽门槛，不改换更有利的统计口径。

**关于效应量与样本量关系的一项说明。** 统计功效分析的基本结论是，可被检出的最小效应量随样本量增大而减小[1]。本文的样本量固定为 $n = 200$，因此存在一个由该样本量决定的分辨下限：小于该下限的真实差异即使存在，也无法与样本波动区分。这一性质决定了 `REJECT_NULL` 的正确读法是"在本样本量下无法区分于零"，**而非"该差异不存在"**。第 6 章对 CD 与 HD 两项的裁定须按此读法理解，本文不将 `REJECT_NULL` 表述为"证明无效"。

本文未在实验前作功效分析以确定所需样本量。这是一项设计层面的不足：样本量 $n = 200$ 的选定依据是与第 3 章诊断口径保持一致，而非由目标效应量与功效水平反推。其后果是本文无法声明"若真实效应量为 $x$，本设计有 $y$ 的概率检出它"。

**配对比较的定位。** 除均值比较外，本文另报逐样本配对的改善占比（200 个样本中方向变好的个数）。本章预先规定该量的性质：**它是描述性事实陈述，不设接收门槛，不作显著性裁定。** 该规定的必要性在于防止一类事后操作——若均值比较未通过门槛而配对计数呈多数，改用配对口径重新裁定即构成按结果选择判据。本章明确：**配对结果无论是否有利，均不改变基于均值门槛的裁定。**

### 4.3.3 内部效度、外部效度和构念效度威胁

本节按效度类型列出本文设计的已知威胁及其处理，凡未处理者明确标注。

**内部效度威胁一：容量混杂。** 若实验组的模型容量高于对照组，改善可能来自容量而非机制。**已处理**：全部组的生成器参数量恒为 1152803，B 系组新增的判别器参数不参与推理。

**内部效度威胁二：超参调优不对等。** 若实验组经过调优而对照组未经调优，比较不公平。**已处理**：全部组共享超参；B1 的固定权重取自实测均值而非调优所得；本文未对 B2 的 $r_{\mathrm{target}}$ 作扫参。

**内部效度威胁三：warmup 的干扰。** 若两组的 warmup 配置不同，差异可能来自 warmup。**已处理**：两组 warmup 完全一致（4.2.1 节因素四）。

**内部效度威胁四：权重量级与动态性的混淆。** GAAW 给出的权重若系统性低于固定值，则收益可能仅来自量级。**未处理**——本文未设置"更小的固定权重"对照组。该威胁是本文最主要的内部效度缺口，第 6.4.3 节与第 7.3.2 节均予列明，本章不以任何方式弱化其表述。

**内部效度威胁五：选点规则的影响。** 各 run 的报告指标取自 `best.pt`，若选点规则对某组更有利则构成偏倚。**部分处理**：选点规则在全部组间一致且训练前固定。但各组的 best epoch 不同（第 6 章将报告 AC 组早至 61），这一差异本身携带信息（提示优化过程被干扰），本文将其作为观察对象报告而非视为噪声。

**外部效度威胁一：单数据集单倍率。** 全部实验在 PU1K、$r = 4$ 上完成。**未处理**，本文不就跨数据集或其他倍率作任何推断。

**外部效度威胁二：单随机种子。** 结论可能是这一次初始化的偶然结果。**未处理**。

该威胁在深度学习实验中并非理论顾虑而有实证依据：已有工作通过大规模重复实验表明，仅改变随机种子即可使同一配置在标准视觉基准上的精度产生可观波动，其幅度足以覆盖许多论文所报告的方法增益[91]。本文的效应量为 8 倍量级的跨样本标准误（第 6 章），与该类波动的关系无法从本文数据判断——因为判断它恰恰需要多种子重复。

本章据此预先规定表述纪律：本文主结论一律表述为"在本次受控运行中观察到"，不表述为"该方法稳定优于对照"。该纪律在第 6 章与第 7 章一律执行。

**外部效度威胁三：合成 patch 数据。** PU1K 的 patch 由合成采样得到，与真实扫描在噪声与密度分布上存在系统差异。**未处理**，本文不就真实扫描数据作推断。

**构念效度威胁一：$\mathrm{cv}_{\mathrm{nn}}$ 能否代表"均匀性"。** 该量度量最近邻间距的变异系数，不涵盖均匀性的全部含义（如是否存在大尺度密度梯度）。**部分处理**：本文同报 NUC 作为交叉参考，但 NUC 为简化实现，其绝对值不与文献值对表。

**构念效度威胁二：P2F 缺失导致表面贴合度无度量。** 本文所用 patch 数据不含网格与法向量，P2F 不可计算。**未处理**，本文不以 CD 或 HD 替代其功能后声称已覆盖表面贴合度。

**构念效度威胁三：训练期与推理期同名指标不同源。** HD 在本文存在两个口径（训练期逐 epoch 监控量、推理期逐样本值）。**已处理**：本章规定二者的离散度统计不可合并，第 6 章分别报告并在插图元数据中以字段固化该警告。

## 4.4 研究假设汇总

本节以表格形式汇总五条假设及其预注册信息。第 6 章按"支持、条件支持、未获支持、待实验"四类给出裁定，**不使用"基本支持"等含混表述**。

**表 4.1  预注册假设汇总（实验前固定）**

| 假设 | 命题 | 对照组 | 指标（统计单位） | 接收条件 | 失败后的处理 |
|---|---|---|---|---|---|
| H1 | 梯度范数比非平凡 | 无（单组轨迹） | $\hat\rho$ 逐 epoch（$n=150$） | 极差 $\geq 100$ 倍，且须通过抗异常点与分段单调核验 | GAAW 降级为权重取值方法，机制论述取消 |
| H2 | B2 相对 B1 改善 CD | B1（同机同种子） | CD 均值（$n=200$） | $\Delta \leq -2\,\mathrm{SE}$ | 不作 CD 有效性主张 |

**四类裁定的定义。**「支持」指接收条件完全满足。「条件支持」指接收条件满足但其解释受本章已声明的效度威胁限制，须附带限定表述。「未获支持」指接收条件不满足，本文不作该项主张。「待实验」指该项所需的对照组本文未设置，无法裁定。

按此定义，本章可预先指出一项确定的"待实验"：**4.3.3 节内部效度威胁四所述的"权重量级与动态性的混淆"，因缺少第三个对照组而无法在本文中裁定。** 该项不因 H1–H4 的成立而被间接解决。

## 4.5 本章小结

本章把第 3 章定位的瓶颈转化为可检验的研究设计。

在假设层面，提出并预注册五条可证伪假设 H1–H5，逐条指定对照组、指标、统计单位、接收条件与失败后的处理方式，并明确三组假设（机制存在性、收益有效性、报告纪律）之间无逻辑蕴涵关系。本章同时预先声明两项预期：H2 与 H3 不预期同时成立（因 CD 与均匀性近乎独立），H5 预期方向不利（因固定权重放大了对抗分支的有效贡献）。

在变量层面，定义四个自变量水平（无辅助项、固定对抗权重、自适应对抗权重、显式均匀性约束）、五项因变量（$\mathrm{cv}_{\mathrm{nn}}$ 主指标，CD、HD 同报，$Q_4/Q_1$ 分层，训练代价）、控制变量集合与机制变量。其中显式均匀性约束作为竞争基线预先规定必须进入主表。

在设计层面，确立三层对照结构，将主对比定为 B1→B2 并记录对第 3.5.5 节的修订理由，同时保留原预注册口径的报告；确立跨机器不并列的红线；确立 $2\,\mathrm{SE}$ 门槛与三档裁定规则，并预先规定配对分析为描述性统计、不用于改判。

在效度层面，逐项列出十二项威胁及其处理状态。其中已处理者五项（容量混杂、调优不对等、warmup 干扰、口径混用、选点一致性），未处理者六项（权重量级与动态性混淆、单数据集单倍率、单随机种子、合成数据、P2F 缺失、NUC 简化实现），部分处理者一项。**本章明确指出，未处理的第一项——权重量级与动态性的混淆——是本文最主要的内部效度缺口**，其后果是即使 H1、H3、H4 全部成立，也不能断言收益源于动态调整本身。
