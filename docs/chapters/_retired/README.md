## 一条值得记住的教训

`_mavis_ch5_overwrite_20260814.md.bak` 的存在暴露了一个真实风险：
**大规模章节重构会静默丢掉内容，而数字审计器查不出来** ——
它只验「写出来的数字对不对」，不验「该写的有没有写」。

实测后果：承载「本文方法在样本 67133 上反而更差」这一不利事实的数字
`0.256054` 曾从全部正稿章节消失，只剩 `docs/EXPERIMENT_LOG.md` 有记录，
而当时全文审计仍是 `issues=0` 全绿。同时两张图（点云定性对比、
保真度—均匀性权衡）在全文零引用。

因此重构后必须额外做两项**审计器之外**的盘点：

1. 遍历图片资产目录，反查每个文件名是否在正文出现 → 抓零引用图；
2. 用本目录的旧稿 grep 关键负面数字，确认其仍在正稿中 → 抓丢失的不利事实。

补回的不利事实已加入篡改负例表（`scripts/_negtest_ch5_tamper.py` 用例 P8），
下次重构若再丢会被立即检出。
