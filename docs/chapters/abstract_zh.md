# 摘要

点云上采样的任务是从稀疏点集生成分布合理的稠密点集，是三维重建与点云分析管线中的关键中间环节。近年基于深度学习的方法在 Chamfer 距离等保真度指标上持续改进，并普遍引入对抗监督以补充分布层面的约束。但已有工作在三个方面存在不足：改进措施与其声称机制之间缺少中间层面的证据；评价口径不统一使跨论文数值难以直接比较；方法的失效条件与负面结果普遍缺失报告。其中一个长期沿用而少经检验的做法是，将对抗损失的权重取为固定常数——该常数是否在整个训练过程中持续表达设计者期望的相对贡献，既缺少实测，也缺少受控对照。

本文以该问题为切入点，在 PU1K 数据集的 4 倍上采样设置下，先复现并核验以 PU-Transformer 为生成器、PU-GAN 式判别器为对抗分支的联合基线，再以实测证据定位其瓶颈，最后在训练机制层面提出改进并作受控验证。

基线核验与瓶颈诊断给出三项结果。第一，本文实现的生成器参数量为 1152803，与原文报告值的比值为 1.1886，差异经逐层核验定位于多头自注意力的输出投影层，并对原文未明写的三项实现细节作了显式标注。第二，以极端对照模型标定各指标的有效范围后发现，各指标的盲区互不重叠，因此多指标联合报告是必要条件。第三，基线瓶颈是局部间距的离散而非整体密度偏差：输出点云最近邻间距的变异系数为真值的 4.22 倍且 200 个样本无一例外，而平均间距比值为 0.916；误差随输入局部稀疏度单调上升，最疏四分位为最密四分位的 1.476 倍。尤为关键的是，最近邻间距变异系数与 Chamfer 距离的秩相关仅为 $-0.217$，即在纯 Chamfer 监督下继续压低保真度误差不会改善均匀性。这构成本文引入辅助监督并以间距均匀性为主指标的直接依据。

针对该瓶颈，本文提出梯度自适应对抗权重（gradient-adaptive adversarial weighting, GAAW），并将采用该机制的完整方法记为 GA-PUT。其做法是保持骨干网络结构不变，依据重建分支与对抗分支的梯度范数比在线调节对抗损失权重，使两分支的相对贡献不再由一个静态常数给定。本文明确该机制的定位：梯度范数比赋权的思想在图像生成领域已有直接先例，本文**不声称首次提出该公式**，其工作是该场景下的机制适配、量化测量与边界界定。

实验在 $n = 200$ 的同口径验证子集上完成，全部裁定依据实验前固定的判据执行。机制层面，两分支梯度范数比在 150 个 epoch 内跨越 $3.92×10^{6}$ 倍，剔除首尾各 10% 分位后仍为 $4.31×10^{5}$ 倍，分段中位数严格单调递增，按领域惯例取定的固定权重在 $91.3\%$ 的 epoch 中偏离实际梯度环境——该测量证实机制确实被触发。效果层面，在同机器、同随机种子、单一变量条件下，梯度自适应赋权相对固定权重赋权在主指标上改善 $6.43\%$，偏移量达跨样本标准误的 8.48 倍，逐样本配对显示 200 个样本中 158 个（$79.00\%$）方向变好，即该改善在样本总体上普遍出现而非由少数样本拉动。Chamfer 距离与 Hausdorff 距离的点估计方向同为改善（$-1.36\%$、$-1.69\%$），说明该改善未以几何保真度或最坏区域风险为代价，但两者偏移量仅为 $0.32$ 与 $0.35$ 倍标准误，低于预设门槛，故本文对这两项**不作有效性主张**。

本文同时如实报告三项对自身不利的结果。其一，引入对抗分支本身在本文配置下损害主指标：固定权重与自适应权重相对无对抗基线分别劣化 $14.86\%$ 与 $7.47\%$，均为反向显著，即自适应赋权将劣化幅度减半但未使其转为改善。因此本文的主张严格限定为「若采用对抗训练，则梯度自适应赋权优于固定权重赋权」，而**不主张采用对抗训练优于不采用**。其二，一个更简单的竞争方案性价比更优：显式均匀性约束在主指标上改善 $5.44\%$，训练开销仅增加 $13.04\%$，无额外参数且不需判别器，而本文方法需增加 $70.58\%$ 训练时间与 255426 个判别器参数。其三，本文方法的收益无法在「动态调整」与「权重量级更小」两种成因之间归因，因为「人工设定一个更小的固定权重」这一对照实验本文未做。此外，双向 Chamfer 权重调整无法替代显式均匀性约束且加权越激进劣化越严重，两个损失项的组合出现负向交互，对骨干补上标准注意力缩放使三项指标同时崩塌——三项失败案例共同界定了方法的失效边界。

本文的可确认工作为四项：该场景中重建—对抗梯度失衡的量化测量；梯度范数比赋权的场景适配与受控验证；包含负面结果、竞争方案与训练代价的完整验证报告；预注册判据的完整执行。全部结论限定于 PU1K 数据集、patch 形式、$N = 256$、$r = 4$ 与单一随机种子的范围内，不作跨数据集、跨倍率或跨骨干网络的外推；跨随机种子的稳健性本文未测量，故主结论的确切表述为「在本次受控运行中观察到」。

**关键词：** 点云上采样；对抗训练；梯度尺度失衡；自适应损失加权；分布均匀性；消融实验
